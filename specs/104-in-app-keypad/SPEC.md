# 104 — 训练页数字输入统一用 app 内数字面板

- **状态**: Ready（2026-11-06 David「1A 2A 3A 4A」确认）；屏幕稿待「定稿」后派 UI 卡
- **来源**: David 真机反馈：今日训练页填辅助项重量时系统键盘挡住正在填的格子（安卓 CN 0.1.0(8)）；iOS 同页系统键盘弹出时底部导航栏浮在键盘上、只剩一行可见。#143（安卓滚动避让）已合 main 但未出包。David 决定不再修补系统键盘，统一改用主项已在用的 app 内数字面板。
- **范围**: 学员端今日训练页。安卓 RN（本仓 `main`）与 iOS（`MeetPR` 仓 `release/1.0`）同批派卡、同批验收；iOS 仓同目录镜像本文件。
- **级别 / 节奏**: T1（单页、复用现成组件，无后端/数据改动），P1。iOS 赶 1.0(33)，安卓随下一个 CN 包。

## 现状（已核实，RN `origin/main` / iOS `origin/release/1.0` e106803b）

- 主项组记录（RN `SetEntrySheet.tsx` / iOS `SetEntrySheet.swift`）已用 app 内数字面板（RN `src/design/NumberPad.tsx`，iOS `DesignSystem/.../MeetPRNumberPad.swift`）：底部弹出，顶部一行上下文 + 大号当前值，3×4 键位，取消/确定；RN 版已支持 `contextText` 与 `onNext`。
- 辅助项、学员自加动作、自选重量/自重行（RN `AccessoryLogCard.tsx`；iOS `AccessoryLogRow.swift`、`LoadTypeLogRow.swift`）的重量、次数、RPE/RIR 是行内 `TextInput`/`TextField`，弹系统键盘。安卓上会被键盘挡住；iOS 上底部 `MeetPRTabBar`（`StudentRootView.swift` 的 `safeAreaInset`）随键盘上浮。

## 变更

1. **范围**：今日训练页所有组内数字格——辅助项、自加动作、自选重量与自重行的重量、次数、RPE、RIR——一律不再弹系统键盘。格子外观保持现在的方框，点按打开 app 内数字面板。其他页面（补记、身体数据等）不在本 spec。
2. **面板**：复用两端现有数字面板组件与样式（同主项）。顶部左侧写上下文「{动作名} · 第 {n} 组 · {重量|次数|RPE|RIR}」，右侧大号显示当前输入值与单位（KG/LB 跟随用户单位，次数显示「次」）。
3. **连续输入**：主按钮在非最后一格时为「下一项」，确定当前值并跳到同组下一格（重量→次数→RPE/RIR），同组最后一格跳到下一组第一格；该动作最后一组最后一格时主按钮为「确定」，确定后面板收起。左侧「取消」只放弃当前格未确定的输入并收起面板。点遮罩等同取消。某格本来就不可编辑（例如自重行没有重量格）时直接跳过。
4. **取值规则**：沿用各格现有的校验与过滤，不套用主项杠铃规则——辅助项重量最小 0、不吸附到杠铃片、最多一位小数；次数整数 1–100；RPE 5–10、步进 0.5（允许小数点）；RIR 整数 0–9（不出现小数点键或按了无效）。RPE/RIR 为可选格时，删空后确定 = 清空该格；重量/次数删空后确定 = 保持原值。
5. **面板打开时的页面**：正在填的那一行高亮（同现在聚焦时的描边色），并把这一行自动滚到面板上沿之上，留出与主项一致的间距；跳到下一格/下一组时跟着滚。面板收起后页面不回跳、底部不留空白。
6. **清理**：今日训练页不再存在弹系统键盘的输入后，安卓 #143 加的键盘避让代码与 iOS 为键盘做的特殊处理一并删除（保留则需在 JOURNAL 写明仍有哪个系统键盘输入依赖它）。导航栏、tab、其他页面键盘行为不动。

## 验收清单

- [ ] 两端：辅助项、自加动作、自选重量、自重行的每种数字格点按均弹 app 内面板，**全程不出现系统键盘**。
- [ ] 面板顶部上下文文案正确（动作名/组号/字段），当前值与单位正确；简中、繁中、英文三语。
- [ ] 「下一项」按 重量→次数→RPE/RIR→下一组 顺序跳转，跳过不可编辑格；最后一格显示「确定」并收起。
- [ ] 取消/点遮罩不改值；RPE/RIR 删空确定=清空；重量/次数删空确定=原值不变。
- [ ] 取值边界：辅助项重量可输 0 与 7.5，不被改成 20 或吸附；RPE 9.5 可输、10.5 被拦；RIR 不可输小数。
- [ ] 正在填的行高亮，并始终在面板上沿之上：分别验证第一张、中间、最后一张辅助卡的最后一组（列表末尾）。
- [ ] 输入后打勾完成、离线保存（spec 102）、完成整日等现有流程结果不变，数值落库正确。
- [ ] iOS：任何时候底部导航栏不再浮在键盘/面板上方。
- [ ] 带历史的老用户升级后第一屏（今日训练页有已完成与未完成辅助项）显示正常，已记录的值不变。
- [ ] 安卓模拟器 `meetpr-cn-accept` 与 iOS 模拟器 `iPhone 17e` 截图存证，两端同批验收。

## 测试 seam

- RN：`AccessoryLogCard` 组件测试——点格子 → 渲染 `NumberPad` 且 `contextText` 正确；`onNext` 依次推进到下一字段/下一组；最后一格 commit 后面板关闭；断言今日训练页树内不存在可编辑的系统 `TextInput`。取值边界复用/扩展 `number-pad.ts` 的单测（新增辅助项取值规则，不改主项 `snapped` 行为）。
- iOS：`AccessoryLogRow` / `LoadTypeLogRow` 的输入状态（view model 或现有测试入口）——字段推进顺序、取消/清空语义、取值边界；面板呈现以模拟器截图为证。

## Out of Scope

- 补记页、身体数据、聊天等其他页面的输入方式。
- 主项组记录面板的任何改动（含杠铃吸附、最小 20 kg 规则）。
- 新增「刻度点选」等其他输入形态；面板视觉重做。
- 教练端。
