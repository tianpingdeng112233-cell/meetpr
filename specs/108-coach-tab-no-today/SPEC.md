## 已拍板（引用即约束，不重议）

1. **删掉今日 tab**。学员底部 tab 依次为 **训练 / 教练 / 成长 / 我的**。冷启动、登录后、绑定成功后，一律落在训练。
2. **教练 tab** = 现网学员聊天页升为第二个 tab。时间线内容和行为不变（聊天消息 + 教练反馈 + 计划发布通知，现网已合在一条时间线里），发消息、发视频、看反馈详情都照旧。
   - 四个 tab 右上角的聊天按钮全部删除（解决 P2-19）。
   - 教练 tab 的角标是**一个数**，口径沿用现网聊天按钮的 `totalUnread`（未读聊天 + 未读反馈 + 未看的计划发布通知）。别处不再显示第二个未读数（解决 P2-20）。
   - 没有教练的账号（`self_train_student`）不显示教练 tab。
3. **比赛 / 体重条**：放在训练页周条上方的一条窄条。
   - 什么时候出现：学员设了比赛（比赛日是今天或以后），**或者**在「我的 › 设置」打开了「每天记录体重」开关。两个都不满足就不出现，页面上不留空位。
   - 写法：有比赛时左边是「距 {比赛名} {N} 天」，比赛当天写「今天比赛」；右边是体重，今天记过写「今天 77.0 kg」，没记过写「今天体重 · 记一下」。没设比赛、只开了开关时，只有体重这一半。
   - 点体重：就地弹出现网的应用内数字面板（spec 105），保存为「今天」这一条。点比赛那一半：跳「我的」里现有的比赛编辑。
   - 这条不跟着周条选的天变：选了以前或以后的周照样显示；空态（等计划 / 计划练完）也显示。
4. **「每天记录体重」开关**：「我的 › 设置」新增一行，默认关，存在本机（按账号）。说明小字写「设了比赛会自动显示」。设了比赛时，开关不影响条的出现。
5. **体重记录 = 后端 046**：一天一条，按手机当地日期，当天再记就覆盖；档案里的「当前体重」等于日期最新的一条。凡是保存体重的入口都记一条，包括比赛 / 体重条、「我的」基本信息、引导第 1 步、体重页，口径同 087 §5。后端没部署 046 的环境（新接口 404）要自动退回档案保存接口，体重照样能存（同 087 §5）。
6. **体重曲线页两端都做**：入口是成长 tab 菜单新增的「体重」一行（显示最新一条，如「77.00 kg」，没有记录显示「—」），页面内容按 087 §5：曲线 + 时间范围、记录今天的体重、记录列表、删单条。安卓接着 087 第二步做；iOS 同构新做。
7. **今日 tab 的状态卡并入训练页空态**（逻辑沿用，只换位置）：
   - 等第一份计划：「{教练} 正在为你排第一份计划」+ 按钮「跟教练说一声」（跳教练 tab）+ 原有「等计划的时候」两项（完善资料 / 填写比赛）。
   - 等下一周计划：「{教练} 正在为你排 W{n}」+「跟教练说一声」。
   - 整个计划已练完：「{N} 周计划已全部完成」+「跟教练说一声」。
   - 「第一份计划到达」卡删掉，训练页直接显示 W1D1。
   - 当天已完成、撤销完成：沿用训练页现网（107 保留）。
8. **删除**（今日 tab 整体下线，以下各项没有新去处）：大标题 W1D1 + 状态胶囊、日期行与 MEETPR 标、本周分段进度条、本周日历、当天概览卡、吸底「开始训练」、营养占位、三项 e1RM 小卡、教练反馈卡（反馈在教练 tab 时间线里）、体重 / 距比赛两格（由第 3 条的窄条替代）、当天已完成卡里的「下一节 · 继续下一节」（周条已覆盖）。
9. **原来跳今日的地方全部改落点**：
   - 长按完成今天之后：留在训练 tab，显示当天已完成态（RN 现网会跳回今日，iOS 是 `onReturnToToday`）。
   - 成长 › e1RM 零数据态的「去今日」按钮改为「去训练」，跳训练 tab。
   - 反馈详情页的返回兜底改回教练 tab。
   - 「我的」编辑页的 `returnTo=today` 删掉，编辑完留在「我的」。
   - 绑定成功欢迎页的「进入」落训练。
   - 推送：计划类推送照旧落训练；**聊天消息推送改为点开落教练 tab**（现网点开不跳转）。

## 存量数据与老用户升级（交付红线）

- 升级后第一屏是训练 tab。带历史的老用户：当天已练完的显示已完成态和撤销（7 天窗口照旧）；当天练到一半的照 107 的存量规则；有未读的，教练 tab 角标数等于升级前聊天按钮上的数。
- 体重：升级前档案里有体重的，由后端 046 回填为第一条记录（日期取档案最后修改日），学员端只负责正常显示、可删。老版本 App 在后端部署 046 后保存体重，也会由后端联动记一条。
- 本机原有的今日 tab 状态（反馈卡展开、首份计划卡已看等）作废无害；`plan-seen` 的已看签名继续供教练时间线使用，不能清。
- 本机「待同步」队列与视频任务不受影响（101/102）。
- 设了比赛的老用户升级后，比赛 / 体重条直接出现；比赛日已过的视为没设比赛。

## 验收清单

1. 冷启动、登录、绑定成功、杀进程重开，都落在训练 tab；底部 tab 依次为训练 / 教练 / 成长 / 我的，没有今日。
2. 四个 tab 顶部都没有聊天按钮；教练 tab 角标数等于未读聊天 + 未读反馈 + 未看计划通知，和时间线里的未读一致；读完角标消失。
3. 教练 tab 里发文字、发视频、点反馈看详情（含视频标注）、计划发布通知，全部和现网聊天页一致；从教练 tab 切走再回来，输入框里的草稿不丢。
4. 聊天消息推送点开落教练 tab；计划推送点开落训练 tab。
5. 设了比赛的学员：训练页出现「距 X 天 · 今天体重 · 记一下」；点「记一下」弹数字面板，保存后显示「今天 77.0 kg」，成长 › 体重页多一条当天记录；当天再记就覆盖，不新增。
6. 没设比赛的学员：默认不出现这条；在设置里打开开关后出现（只有体重）；关掉后消失。设了比赛的学员，开关关着也出现。
7. 体重页：曲线、范围切换、记录列表、删单条、删到一条不剩时当前体重清空，两端一致；后端返回 404 的环境，保存体重退回档案接口，体重仍能存上。
8. 等第一份计划、等下一周、计划已练完三种状态出现在训练页，「跟教练说一声」跳教练 tab；「完善资料 / 填写比赛」可达。
9. 长按完成今天后留在训练 tab，显示已完成态；撤销仍可用。e1RM 零数据态的按钮跳训练；反馈详情返回落教练 tab。
10. 第 8 条列出的删除项都不可达，搜不到残留文案（按「改概念先扫旧残留」：两端全仓 grep「今日」tab 名、「开始训练」吸底、「本节 · E1RM」、营养占位文案，列入收货）。
11. 老用户升级：用带历史的账号（当天已完成 / 练到一半 / 有未读反馈 / 档案里有体重 / 设了比赛）各升级一次，第一屏和上面各条一致；深浅两色都看。
12. `self_train_student` 账号没有教练 tab，也不崩。
