# Spec 083 — e1RM 节点溯源与训练历史入口

- 状态：Draft；产品行为已由 David 于 2026-09-14 确认，正式双主题交互设计待看稿。
- 级别／节奏：T2 / P1；基于 `release/1.0`，本稿不代表已进入发版候选。
- 基线：`202e95dbbf88baf5778f2329f206f34e117a4dd0`，2026-09-14 已核远端。
- 开工先读已有 `CONTEXT.md`。范围为学员端，复用当前数据与计算规则。

## 目标与已确认行为

1. 深蹲、卧推、硬拉的成长曲线显示可点击节点，用户能查到来源日期、哪一组及计算过程。
2. 节点沿用当前每日最佳口径：只在有有效 e1RM 记录的训练日取最佳组；无记录日期不补点，不要求每天训练，不限于突破历史纪录。一次有效训练相隔一周时，节点也相隔一周。
3. 训练页增加「历史记录」入口，打开现有全部训练历史，保留其动作筛选；返回时保留当前训练状态。
4. 风格以 David 提供的 `MeetPR 学员端 双主题（离线版）.html` 为参照；旧稿细节不覆盖当前 App 的导航、数据和训练形态。

## 现状与边界

- `GrowthScreenPresentation.snapshot` 消费 `visibleDailyBestSamples`，不是滚动最高线。卡片大数仍按既有 rolling-max 口径，节点详情必须绑定所点样本。
- 每日归组和同值优先级复用 `E1RMSeries.dailyBestEligible`；不增加强度阈值、不替换公式、不改变低置信隔离规则。
- `E1RMHistoryPoint` 已保存 `setLogId`、日期、源重量、次数、学员 RPE、教练 RPE、origin 和 confidence。
- 当前历史入口在成长页，`AllHistoryScreen` 复用 `HistoryEntriesView`。入口复用既有历史覆盖范围；跨计划历史能力不在本次扩大。

## UI 设计约束

流程为 spec → 正式 UI 设计和可交互 demo → David 看稿确认 → SwiftUI 实装。此前 scratch 中的简化 `preview.html` 仅作行为确认，不作为正式视觉正典。

正式 demo 覆盖暗色和亮色、成长曲线、选中节点、详情面板、训练入口、历史页与返回。界面沿用参考的品牌金、分层表面、等宽数值、清晰标题、圆角卡片和既有 tab；仅设计本次增量，不重做全 App。

### 节点和详情

- 主线每个真实样本显示节点，选中态用品牌金突出；密集节点按最近位置选择，不能只让末点可点。
- 点击节点出现底部详情面板；关闭后保留图表时间范围、滚动位置。不同动作、不同时间窗不能沿用过期选择。
- 展示来源训练日期、动作名、组次（原始 `setIndex + 1`）、实际重量 × 次数、RPE、e1RM 结果、计算说明。教练校准优先时明确标注采用教练 RPE，同时保留学员原报值。
- 有适用 RPE 时展示当前 `E1RMCalculator` 所用表值与除法；缺失或低于其查表范围时展示当前 Epley fallback。说明与现有计算一致，不另写一份近似表。
- 持久化结果是所选节点的数值；如果旧数据不能复现算式，显示已保存结果并说明计算明细不可完整还原，不伪造等式。
- imported 来源标明「导入记录」；低置信来源保留现有弱化样式并说明未计入可信趋势，不因点选升级为可信数据。
- 原始日志或计划已不可用时，仍展示点中保留的来源数值；缺失组号显示「原始组信息不可用」，不猜测、也不借用当前计划的同名动作或同序号组。
- 空态、成形态、图表解锁门槛仍沿用当前规则；本次不引入新的解锁标准。

### 历史入口

- 在当前训练页顶部增加轻量「历史记录」入口；保留刷新、状态和消息入口。确切位置由正式 demo 确认。
- 在训练页导航栈内打开历史记录，返回仍停留原训练日；已开始状态、已记组、草稿和计时不因导航重置。
- 复用全部历史展示与动作筛选；加载、失败可重试、无历史状态明确可返回。
- 中英文用户可见文本走当前本地化体系；两种主题下交互区域至少 44pt，支持 VoiceOver 读取节点日期与估算值。

## 实现单元与测试 seam

两张独立验收卡：A 节点与来源详情；B 训练历史入口。主代理单写者实现。

- A：以 `GrowthCurveViewModel` 的样本／来源查询和新增详情投影边界为 seam，通过仓储输入验证「点到哪天就显示那天赢家」；覆盖同日多组、隔周节点、同值日期、教练校准、fallback、导入和缺失原始日志。数值例：152kg × 5 @8，当前表值 0.78，结果显示 194.9kg。
- B：以历史 ViewModel 的加载／重试边界和真实导航操作为 seam，验证正常、空与失败状态；模拟器验证进入历史再返回时训练状态保持。
- 不测私有绘图 helper；节点命中、密集点、长文本和双主题通过实际 UI 操作验证。

## 验收

- [ ] 一周一条有效估算只出现一周一个真实节点，无合成日期节点。
- [ ] 同日多个有效组显示当日最佳来源；不同日同值仍能分别查看。
- [ ] 选中历史节点的日期、组、RPE、算式和结果相互一致，不误用卡片大数或末点。
- [ ] 原始组缺失、导入记录、教练校准与 fallback 都有诚实的来源说明。
- [ ] 训练页可直接进入历史、筛选动作、返回训练且状态保持。
- [ ] 受影响包测试、build、strict lint、format 通过；Standards／Spec 独立审查收敛。
- [ ] DemoStudent 双主题实点与截图；持久化兼容用已有历史 fixture 验证，Demo 不冒充真实后端验收。
