### Step 5 of 7 — 恢复能力（v2：5 级中文 + 工作强度 U 型量表）

| 字段 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| 日常生活强度 | 滑块 5 级（U 型）| 是 | 整体强度指标——久坐和高体力两端都消耗恢复 |
| 生活压力 | 滑块 5 级 | 是 | 心理 / 情绪压力 |
| 恢复速度 | 滑块 5 级（保持 v1） | 是 | 训练后多久不酸了 |
| 睡眠时长 | 滑块 5 档（保持 v1） | 是 | |

**v2 新 5 级标签**（**v2.1 修订工作强度**）：

| 滑块 | 1（最佳）| 2 | 3 | 4 | 5（最高负荷）|
|---|---|---|---|---|---|
| **日常生活强度** | 适度活跃（每天 30+ 分钟自然走动 / 站立 + 不疲劳）| 偏轻负荷（轻度办公 / 学习 + 通勤步行）| 中等负荷（**久坐为主** 6+h/天，办公 / 长时间上课 / 中等体力）| 较高负荷（密集脑力 + 久坐 OR 较高体力劳动 OR 备考 / 项目冲刺期）| 极高负荷（高强度体力劳动 / 多班次轮班 / 极端 deadline）|
| 生活压力 | 几乎无压力 | 偶尔有压力 | 中等压力 | 较高压力 | 极高压力 |
| 恢复速度 | 很慢（>72h）| 慢（48-72h）| 正常（24-48h）| 快（12-24h）| 很快（<12h）|
| 睡眠时长 | ≤5h | 6h | 7h | 8h | 9h+ |

> **为什么工作强度是 U 型**：力量举训练恢复看的是"额外消耗"。**久坐绝不是低消耗**——长时间不动 = 循环差 / 髋部紧 / 心理疲劳，这些都从恢复池里抽。极端体力劳动同样大量消耗。中间适度活跃才是最佳基线。所以**久坐放在第 3 级（中等）而非第 1 级**，避免学员误以为"我坐着工作所以恢复负担小"。

| Type | 字段 | 权限模型 | 学员看到 |
|---|---|---|---|
| **A. 锁定** | 1RM（深蹲/卧推/硬拉）/ 训练日 / 训练环境（gym tier）| cycle 中只读，仅教练端可改 | 字段灰色 + "需联系教练修改" |

| **C. 学员可改 silent** | 想增强肌群 / 比赛日期 / 给教练备注 | 学员能改，silent 保存 | 字段可编辑 + 静默保存（无提示）|
| **D. 学员可改 silent（基础）** | 身高 / 体重 / 联系方式 / 单位制 | 学员能改，silent 保存 | 字段可编辑 + 静默保存 |

```
┌─────────────────────────────┐
```

**为什么不让学员 cycle 中改 1RM**（office hours Q-2.1 决议）：

- 学员自评 1RM 可能不准（错记 / 状态影响），改了之后教练计划无效
