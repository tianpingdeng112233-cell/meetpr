## 教练端完整流程（v4 修订）

```
Step 0  选学员
    ↓
Step 1  选计划长度：1周 / 4周
    ↓
Step 2  定 SBD 频率 → 分配到训练日（可加载模板/复制上周/从零开始）
    ↓
Step 3  每天选主项动作
    ↓
Step 4  每天添加辅助动作
    ↓
Step 5  填写 Week 1 强度（计算器弹出）— W1 必填
    ↓
Step 6  递进/递减规则设置（v4 重构：主项 + 辅助项同一套规则）
    ↓
Step 7  规则应用周 + Excel 式预览（v4 重构：删除"是否减载"，规则按周分配）
    ↓
Step 8  发布
    ↓
Step 9  是否保存为模板？→ 命名 → 按"X 天/周 + 1/4 周"归档
```

### Step 2: SBD 频率 → 分配到训练日

顶部提供**使用模板**和**复制上周**入口。模板按已选周数（1 周/4 周）+ 学员训练天数自动过滤。

**复制上周（v4 显式确认 1 周和 4 周都支持）**：
- 1 周模式：从最近一份给该学员的 1 周计划加载（动作 + 组数 + 次数 + 实际重量）
- 4 周模式：从最近一份给该学员的 4 周计划加载（含规则）

```
┌──────────────────────────────────────────┐
│ 张三  S:180 B:120 D:220  4天/周  [展开▼] │
├──────────────────────────────────────────┤
│                                          │
│ [使用模板 ▼]       [复制上周]            │
│  ↑ 自动过滤         ↑ 从上周实际计划加载  │
│  4天+1周/4周模板     无上周计划时灰掉     │
│                                          │
│ ── 或从零开始 ──                          │
│                                          │
│ 训练日：周一·周三·周五·周六 (来自学员档案) │
│                                          │
│ 三大项每周各练几次？                      │
│                                          │
│ 深蹲  [2次/周 ▼]                         │
│ 卧推  [2次/周 ▼]                         │
│ 硬拉  [1次/周 ▼]                         │
│                                          │
│ 分配到训练日：                            │
│                                          │
│ 周一: [深蹲 ▼] [卧推 ▼]                 │
│ 周三: [卧推 ▼]                           │
│ 周五: [硬拉 ▼] [深蹲 ▼]                 │
│ 周六: [— ▼]                              │
└──────────────────────────────────────────┘
```

- 点"使用模板" → 预填模板的动作和规则，教练填 Week 1 重量
- 点"复制上周" → 预填上周的动作和实际重量，教练直接改要改的数字
- 都不点 → 从零开始走 Step 2-4

### Step 5: 填写 Week 1 强度（W1 必填）

所有数字输入弹出**计算器键盘**。强度两种模式：**重量**（内置 kg/%1RM 切换）和 **RPE**。

> **v4 强调**：Week 1 是教练手动写完整的基线。无论 1 周还是 4 周模式，W1 都不能"复用上周"或"自动生成"——必须填完整组数 × 次数 × 强度。后续周才能依靠规则递推。

```
┌──────────────────────────────────────────┐
│ 张三  S:180 B:120 D:220  4天/周  [展开▼] │
├──────────────────────────────────────────┤
│ Week 1 必填（基线）                       │
│                                          │
│ 竞技深蹲（主项）                          │
│ 强度模式:  [重量]  [RPE]                 │
│ RPE 模式:                                 │
│ 组数: [4]   次数: [5]   RPE: [7]         │
│                                          │
│ ──────────────────────────────────────── │
│ 哈克深蹲（辅助项）                        │
│ 重量模式:   [kg]  [%1RM]                 │
│   kg:    组数: [3]  次数: [10]  [60kg]   │
│   %1RM:  组数: [3]  次数: [10]  [33%]=60kg│
└──────────────────────────────────────────┘
```

> 1 周模式 Step 5 后直接跳到 Step 8 发布；4 周模式继续 Step 6。

### Step 6: 递进/递减规则设置（v4 重构 — 主项 + 辅助项同一套规则）

> **核心变化**：主项和辅助项使用**同一套规则类型**——9 种递进/递减选项 + 自定义。规则可应用到任何主项或辅助项，不再有"主项规则" vs "辅助项规则"之分。

#### 9 种规则类型

| # | 规则名 | 教练操作 | 示例 |
|---|------|---------|------|
| 1 | **重量递增** | 选每周增量 + 勾选动作 | +5kg / 周 |
| 2 | **重量递减** | 选每周减量 + 勾选动作 | -10% / 周（taper）|
| 3 | **RPE 递增** | 选每周增量 + 勾选动作 | +0.5 / 周（autoregulation peaking）|
| 4 | **RPE 递减** | 选每周减量 + 勾选动作 | -1 / 周（deload）|
| 5 | **组数递增** | 选每周增量 + 勾选动作 | +1 组 / 周（volume accumulation）|
| 6 | **组数递减** | 选每周减量 + 勾选动作 | -1 组 / 周（peaking）|
| 7 | **次数递增** | 选每周增量 + 勾选动作 | +1 次 / 周（hypertrophy block）|
| 8 | **次数递减** | 选每周减量 + 勾选动作 | -1 次 / 周（intensification）|
| 9 | **自定义** | 手填每周数值 + 勾选动作 | 复合多维度（如 +5kg + -1 次）|

#### 规则与动作的多对多关系

- 每条规则可应用到多个动作（主项或辅助项）
- 每个动作可被多条规则应用（不同维度）
- **冲突处理**：如同一动作被两条规则应用同一维度，后写入优先；UI 高亮提示
- 一个动作可以**完全不被任何规则覆盖** → 默认"同上周"（W2-W4 都等于 W1）

### Step 7: 规则应用周 + Excel 式全局预览（v4 重构）

```

│                                          │

## §α e1RM 计算（v4.2 新增 - 议题 1 决议）

> **议题 1 决议**：e1RM 公式 = **RPE-based + Epley fallback**。

### §α.1 公式选择逻辑

```
对每组 working set (set_type='working') 计算 e1RM:
  if RPE is recorded:
    use RPE-based formula (RTS/Sheiko 表 lookup)
    e1RM = weight / RPE_table[reps][RPE]
  else:
    fallback to Epley:
    e1RM = weight × (1 + reps/30)
```

### §α.2 触发与展示

**触发**：每次训练完成后（训练 session 标记 completed）系统自动 recompute 该 session 包含的所有 working sets 的 e1RM。

**展示**（学员侧 - PRD §5 P0 #16）：
- 三大项 e1RM 折线图（基础版，单条平均线，每个动作 / variation 独立）
- 显示**近 4 周最高 e1RM**（避免单点暴跳）
- e1RM 突破历史最高 → 自动推送学员（"今天你的 squat e1RM 突破！"）

**教练侧**：
- 学员详情页能看到该学员的 e1RM 曲线（同学员侧组件，权限层）
- **教练侧不被 PR 推送**（只主动看曲线）

### §α.3 1RM vs e1RM 区分（议题 6 重塑）

| 字段 | 来源 | 触发更新 | 用途 |
|---|---|---|---|
| 1RM | 学员 onboarding 自填 / 教练手动改 / V2 比赛日 | 锁定，不被训练日 PR 改 | 计划中 % 重量基线 |
| e1RM | 系统每次训练后自动算 | 每个 working set 后 recompute | "进步指标"，曲线 + PR 推学员 |

详见 [[evaluation-workflow]] §0.1 + [[data-model]] e1RM_history。

[接收] 弹模态 2 选 1：
  - 进 7 天评估期 → 创建 evaluation_period 记录
  - 跳过评估期（熟人）→ 直接 bind + 教练可立即排正式计划
        ↓
[评估期内] 7 天硬截止
  - 教练能：看资料 / 留言 / 发"适应周"（不是正式 4 周）
  - 教练能：进入 Step 1 选"1 周"模式给学员发适应周训练
  - 教练不能：在 Step 1 选"4 周"模式（系统拦截）
        ↓
教练填评估总结（3 自由文本字段）
        ↓ 软推荐
弹"立即排第一份计划 / 稍后"
        ↓
教练点"立即排"→ 进入 Step 1 编排流程，预填该学员 1RM/训练日/训练环境
```

## §Y Type A 锁定字段 cascade 模态（v4.1 新增 - office hours Gap #2 Q-2.3）

教练在教练端改 Type A 锁定字段（1RM / 训练日 / 训练环境）后，触发模态。

### §Y.1 触发场景

教练在哪改？
- 学员详情页 → "学员信息"卡片 → 编辑 1RM
- 学员详情页 → "训练日 / 训练环境"卡片 → 编辑

### §Y.2 模态 UX

```
教练保存改动 →

┌──────────────────────────────────┐
│ 张三的训练计划已受影响              │
│                                  │
│ 当前 cycle (Week 2-4) 还在进行    │
│ 你的改动会怎么处理？               │
│                                  │
│ ● 重排 cycle                      │
│   跳到编排页 → 调整 W2-W4         │
│                                  │
│ ○ 不动                            │
│   当前 cycle 仍按旧值，新值用于    │
│   下个 cycle。学员侧会看到："你的 │
│   1RM 已更新，但当前 cycle 仍按   │
│   旧值"                          │
│                                  │
│ ○ 提前结束 cycle                  │
│   当前 cycle 终止于 W_n，学员立即  │
│   收到"教练结束当前训练周期，请等  │
│   待新计划"                       │
│                                  │
│ [取消]              [确认]        │
└──────────────────────────────────┘
```

**3 个选项的具体后续**：

| 选项 | 后续动作 |
|---|---|
| ①重排 | 跳到 Step 1 编排页加载当前 cycle → 教练直接调整 W2-W4 |
| ②不动 | 当前 cycle 不变。学员推送"档案已更新，当前 cycle 按旧值" |
| ③提前结束 | 当前 cycle 终止于 W_n（n = 当前周）。学员推送"教练结束当前训练周期，请等待新计划"。教练随后排新 cycle |

## §Z 教练改 cycle 计划的学员端推送规则（v4.1 新增 - office hours Gap #5 Q-5.2）

教练在编排页修改了已发布 cycle 的某些 day / 动作 / 重量 / 次数 / RPE 等。

### §Z.1 推送层级规则

| 改动场景 | 推送层级 | 学员端表现 |
|---|---|---|
| 24h 内训练日的改动 | **高优先级紧迫推送** | 主页红点 + 推送"⚠️ 教练刚刚调整了你明天的训练，请查看" |
| 其他训练日的改动 | normal 推送 | "教练更新了你 W2 的训练计划" |

### §Z.2 推送文案

**普通推送**（W2 + 改动）：
```
"教练更新了你 W2 的训练计划"
点击 → 跳到训练页查看具体内容
```

**高优先级推送**（24h 内训练日改动）：
```
"⚠️ 教练刚刚调整了你明天的训练，请查看"
主页红点 + 训练日卡片 highlight
```

### §Z.3 学员看不到的细节

- 详细 diff（具体哪个字段从 X 改到 Y）—— V1 不做，V1.5 评估
- 教练改动的原因 / 备注 —— 教练若需告知，走"留言"通道

### §Z.4 教练侧编辑保存的 UX

教练在编排页修改 → 保存 → 系统判断该改动是否落在学员"24h 内的训练日"
- 是 → 学员收到高优先级推送
- 否 → 学员收到 normal 推送

教练侧无额外操作（系统自动判断）。

## 强度输入

只有两种模式：**重量** 和 **RPE**

```
[重量]  [RPE]

重量模式内置切换:
  [kg]  [%1RM]

  kg:    [140] kg
  %1RM:  [78] % = 140.4kg  ← 实时换算，最终都存 kg
```

所有数字输入弹出计算器键盘，不弹默认输入法。
