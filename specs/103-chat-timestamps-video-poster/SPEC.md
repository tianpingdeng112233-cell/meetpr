# 103 — 聊天时间分隔 + 视频首图

- **状态**: Ready（2026-11-06 David「1A 2A」确认）
- **来源**: 学员反馈（2026-11-06 截图）：「聊天页面对话加个 time stamp，聊多了感觉有点串」「发送的视频加个首图，不要全黑的」。
- **范围**: 学员端与教练端的聊天页，安卓 RN（本仓 `main`）与 iOS（`MeetPR` 仓 `release/1.0`）同批派卡、同批验收；iOS 仓同目录镜像本文件。首图依赖后端 spec 060（`MeetPR-backend/specs/060-video-poster`）。
- **级别 / 节奏**: 时间分隔 T1；首图 T2（跨后端）。均 P1。
- **屏幕稿**: 不另出。时间分隔复用现有顶部时间那一行的样式；首图只是填进现有封面区，布局不变。

## 现状（已核实，RN `origin/main` 3aa7fe4 / iOS `origin/release/1.0` 7bef3a2e / 后端 `origin/staging` b61e520）

- 学员聊天（RN `StudentConversationScreen.tsx:294` / iOS `StudentBlackGoldChatView.swift:183`）只在整条时间线最顶上显示一次 `chatTimestamp(items[0].occurredAt)`，之后每条都没有时间。教练聊天（RN `ConversationScreen.tsx` / iOS ChatUI 会话页）同样没有逐段时间。
- 教练反馈卡、学员分享组视频卡的封面是固定深色底 + 播放钮，没有任何图片。时长角标读 `video.durationSeconds`，后端从没下发过时长，所以永远显示「—:—」。
- 后端视频存阿里云 OSS，客户端拿签名 GET 链接播放；没有封面字段，也没有时长字段。

## 变更

### 1. 时间分隔（学员端 + 教练端聊天页）
- 时间线（消息、教练反馈卡、计划卡等一切条目，按现有 `occurredAt` / `created_at`）里，**第一条前面**以及**与上一条间隔 ≥ 5 分钟**的条目前面，插一行居中小字时间。
- 样式沿用现在顶部那行（RN `font.body(11)` + `colors.textDim`；iOS 同口径），上下留白与它一致。原来单独的顶部时间行并入这套规则，不重复显示。
- 文案格式按设备本地时区：

| 情况 | 简中 | English |
|---|---|---|
| 今天 | 19:34 | 19:34（跟随系统 12/24 小时制） |
| 昨天 | 昨天 19:34 | Yesterday 19:34 |
| 7 天内 | 周三 19:34 | Wed 19:34 |
| 今年更早 | 11月3日 19:34 | Nov 3 19:34 |
| 往年 | 2025年11月3日 19:34 | Nov 3, 2025 19:34 |

  繁体中文走现有繁体生成流程。
- 发送中（pending）的消息按本机发送时间参与分组；发送成功换成服务端时间后不跳动到别处（同一分组内即可）。
- 加载更早历史时，新插入的那批与原第一条之间按同一规则重算，不留重复分隔。

### 2. 视频首图（教练反馈卡 + 学员分享组视频卡，两个角色看到的都改）
- 卡片封面区显示后端下发的 `poster_url`（spec 060）：等比裁切铺满（cover），叠在上面的播放钮、动作标签、时长角标保持原位，播放钮和角标加一层轻微暗色底确保在亮图上看得清。
- 图片加载中、`poster_url` 为空、或加载失败 → 回到现在的深色底，不显示错误。
- 首图走客户端图片缓存；签名链接过期后用下次拉取到的新链接，不弹错。
- 时长角标：后端下发 `duration_seconds` 时显示 `m:ss`；没有时**整个角标不显示**（不再出现「—:—」）。

## 验收清单
1. 学员端、教练端聊天：第一条上方有时间；连续 5 分钟内的几条之间没有分隔；隔了 ≥ 5 分钟的两条之间出现一行时间；文案五档格式各用一条造数据验到（今天/昨天/7 天内/今年/往年）。
2. 上拉加载更早历史后，不出现两行相同的时间分隔，原顶部时间不重复。
3. 发一条新消息：发送中就带分组（若距上一条 ≥ 5 分钟则先出时间），发送成功后位置不跳。
4. 教练反馈卡、学员分享组视频卡：对 staging 上**已有的老视频**也显示首图（不是黑底）；截图里 MonsterXTY 那类反馈卡验一次。
5. `poster_url` 为空 / 断网 / 链接 403：显示原深色底，卡片可正常点开播放。
6. 时长：有 `duration_seconds` 显示 `m:ss`；无则角标不出现，界面任何地方不再出现「—:—」。
7. 深浅色两套主题、动态字体放大下时间行不截断、首图上的播放钮看得清。
8. 带历史的老账号升级后第一屏：聊天记录完整、顺序不变、无闪退。

## 测试 seam

- 首图/时长：RN 在现有 `student-conversation-screen.test.tsx`（已有「—:—」断言，改为断言角标不出现）补 poster 有/无两例；iOS 在 ChatUI 封面视图的 presentation 层补同样两例。

## Out of Scope
- 每条消息气泡单独带时间（1B 未选）。
- 消息长按看精确时间、已读时间。
- 聊天里普通图片消息的缩略图（已有）。
- 训练页、历史页等聊天以外地方的视频封面。
- 自定义首图（让学员挑帧）。
