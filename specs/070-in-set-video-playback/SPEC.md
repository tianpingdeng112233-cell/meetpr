# Spec 070 — 组内视频回看 + 本地留存至训练日结束

- **状态**: Approved（David 2026-08-06 拍板 B：组内播放入口 + 本地延迟清理）
- **分级**: T1 / P1（骑在 spec 069 分支上实装；#308 合并后 rebase 到发版线单独开 PR，不挡 1.0(18) 班车则随车，否则下一班）
- **背景**: 「组间回看自己动作」是力量举高频需求。现状：录完确认页可回放，点「使用」后
  本地文件随上传完成即删，组录入页无播放入口——回看要跳出 app 去相册。

## 目标

### A. 组录入页播放入口

- attached 态（含上传中/已送达）新增**播放**入口：优先形态=「视频」label 区域变为可点
  （play 图标 + 现有送达状态行保留）；若与现有「重拍/更换/删除」chips 排布冲突，实装者
  按 DesignSystem 现有 chip 样式自行取舍，验收以模拟器亲验为准。
- 播放来源：**本地文件存在 → 播本地**（秒开零流量）；本地已清 → 经
  `GET /uploads/:attachmentId/url` 拉云端播（接口现成）。复用学员端现有共享播放器组件
  （markers wave 落的那套），不新造播放器；打点列表在此入口**不需要**（纯自查场景，
  没有教练反馈上下文），播放器以纯回放形态呈现。
- 云端加载失败/弱网：轻量错误态（一行提示 + 重试），不阻塞组录入页。
- **扫视态零改动**：组列表「已附视频」不加播放，训练列表/今日页不动。

### B. 本地留存改「训练日结束」清理

- 上传 complete 后**不再立即删除**导出文件：保留 `localFileName`，供组间本地回看。
- 清理策略（替代「传完即删」）：
  1. **冷启动清扫**：app 启动时删除「已上传且非当天」（设备本地日历日,与既有 gym-day
     口径分裂已知,此处取设备本地日,简单为先）的本地视频文件,置空 `localFileName`。
  2. 附件**删除/更换**时即时清理（现行为不变）。
  3. 终态失败/取消的残片清理三路径语义**完全不变**（069 的回收契约）。
  4. **护栏**：留存文件总量 >500MB 时按最旧优先清到限内（防御异常堆积）。
- 播放入口在本地文件被清后自动落到云端路径（同一入口,无感切换）。

## 文件范围

- `VideoAttachmentSection.swift`（播放入口 UI）+ 播放呈现（复用共享播放器的薄封装）
- `VideoUploadManager*`（complete 不删文件；新增冷启动清扫与护栏）
- 对应单测（清扫策略决策表：当天保留/隔天清/超额清/删除更换即清；播放源选择：
  本地存在→本地,不存在→远端 URL）
- **不动**：上传管线语义、`VideoExporting`、后端、069 的重试/后台/通知逻辑

## 硬约束

1. 清扫决策抽纯函数（输入=文件清单+状态+日期,输出=删除集合）,macOS host 真测。
2. 播放本地文件时若上传仍在进行,不得干扰上传（只读打开）。
3. 云端 URL 有效期短,每次播放现取,不缓存 URL。
4. swiftlint --strict / swift-format --strict / 全量测试绿；模拟器亲验播放入口两态
   （本地播放、清后云端播放）。
