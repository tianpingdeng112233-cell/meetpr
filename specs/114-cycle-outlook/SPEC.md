## 背景

学员以前用 Excel 看计划，先翻到后面几周，看这个周期能推到多重。App 里只能一天一天点，按 RPE 排的计划后面几周连重量都没有。

## 已批准行为

### 入口
训练页标题（`W2`）右边加一个「整个周期」胶囊。点开是底部弹层，点遮罩或下滑关闭。现有导航、tab、周条不变。

胶囊出现的条件：当前看的是已发布计划，并且计划里至少有一周排了下文三个主项之一。

spec 110 交接预览（旧周期没练完时往右滑看到的下一份计划，只读）里也有胶囊，打开看的是下一份计划：所有柱子都是「还没练」，没有本周、没有 ✓；点柱子跳到下一份计划里的那一天，仍然只读。

### 弹层内容
- 标题「整个周期」。右侧写「计划名 · N 周」；只排了一部分周时改成金色「已排 n / N 周」。
- 只列三行：竞技深蹲、竞技卧推、硬拉（相扑或传统，跟这份计划里练的那个），按这个顺序。用动作库的主项家族与竞技项属性判定（两端现有的 competition-lift 解析），不看教练勾的主项标记。计划里完全没有的项不画这一行。
- 每行一排柱子，一周一根，`N` = 计划总周数（`plan_weeks`）。

### 每根柱子取哪一组
这个主项当周所有工作组（不含热身组）里分数最高的那一组（分数见下文）。一周里练两次这个主项时，同样取全周分数最高的那一组，并记下它所在的那一天（David 11/23 确认）。

已练完的周改用实际记录：在那周这个主项的实际组里取分数最高的一组；处方仍用于判断「没做满」。那周练了课但这个主项一组都没做，柱顶写「没做」。

### 柱顶文字（两行，上大下小）
| 这一组的写法 | 上行 | 下行 |
|---|---|---|
| 写了重量 | `150` | `×5`，写了 RPE 时 `×5 @8` |
| 只写 RPE，能按学员当前 e1RM 查扩展版 RPE 表（spec 106）折成 kg | `约232.5` | `×2 @7.5` |
| 只写 RPE，学员没有 e1RM，但这一行有教练写死重量的周（混合周，M2） | `约72.5` | `×3 @8` |
| 百分比，能按登记 1RM / e1RM 折成 kg（沿用训练页口径） | `102.5` | `×3` |
| 只写 RPE，没有 e1RM | `3 @8` | `RPE` |
| 百分比，没有登记 1RM | `85%` | `×3` |
| 区间（重量区间 / RPE 区间） | 取区间上限后按以上规则 | |
| 已练完的周（实际） | `160` | `×5`；少做时 `×2/3`（「2」用现有「没做满」的颜色）；写了 RPE 时加 ` @8` |
| 已练完、这个主项没做 | `没做` | |

混合周的估计 e1RM（M2）：只在学员没有 e1RM 时用，取这一行里教练写死重量的周按 Epley（重量 × (1 + 次数 / 30)）算出的最大值，只用于这一行，不写回学员数据。

单位跟随学员的 kg / lb 设置，格式沿用全天一览。按顶组百分比（`top_set`）的组在练之前算不出，按「百分比、没有登记 1RM」那一行写。

### 柱高
每个主项各算各的。每根柱子算一个分数：

```
分数 = 强度² × (1 + 0.03 × 次数 − 0.03 × RPE*)
```
- 强度：能折成 kg 就用 kg（含实际记录）；否则用百分比（85% → 0.85），或 RPE 表查出的 %1RM。
- RPE*：只在教练写死了重量（固定重量、重量区间）且写了 RPE 时扣，实际记录同理（处方写死重量的那周，实际 RPE 也扣）；按 RPE 折算出来的重量已经含了 RPE，不再扣。
- 「没做」的周按处方算高度，不参与金色。
- 同一行里只要有一周能折成 kg，换不成 kg 的周就不参与比较，画成 0.6 中等高度。
- 柱高比例 = (分数 − 下限) / (最高分 − 下限)，下限 = min(最低分, 最高分 × 0.85)。最低 12pt，最高 72pt，按比例插值。所有参与比较的周分数相同时，比例统一 0.6。
- 公式系数（2、0.03、0.03、0.85、0.6）写成具名常量，两端一致。

### 颜色与状态
| 状态 | 画法 |
|---|---|
| 已练完的周（那一天已结算） | 浅金填充柱（金色约 32% 透明度），柱顶文字主色；周标签前加金色 ✓ |
| 本周 | 浅色柱 + 金色描边 |
| 还没练的周 | 浅色实心柱 |
| 分数最高的周 | 金色渐变柱，柱顶文字和周标签也是金色；并列取最后一周。只在参与比较的周里挑。最高的周就是本周时，金色渐变外再加一圈金色描边 |
| 教练还没排的周（`week_number` 在 1…N 内但没有任何训练日） | 同样高的虚线框，柱顶写「未排」，不可点 |
| 那周排了课但没有这个主项 | 一条底线，柱顶写「没练」，不可点，不参与比较 |

浅金填充用现有金色 token 加透明度。深浅两色都用现有设计 token，不新增颜色。

### 周数与滑动
- 不超过 5 周：柱子铺满弹层宽度。
- 超过 5 周：柱宽固定（约 56pt），三行一起左右滑动（滑一行，另两行跟着动）；打开时让本周落在左数第二根（本周是第一周时从头开始）。
- 周标签 `W1`…；本周写 `W2 本周`。

### 点柱子
关闭弹层，周条和全天一览切到这根柱子所在的那一天，行为同点周条里那一天。已练完、本周、后面的周都可以点；未排、没练不可点。

### RPE 对照表页
成长 tab 的列表最后加一行「RPE 对照表」，点进是一页：
- 顶部分段：深蹲 / 卧推 / 硬拉 / %。默认选计划里练得最多的那个主项；没有计划时选深蹲。
- 分段下面一行大字写这个主项学员当前的 e1RM（`265`）+ 小字 `e1RM · kg`。
- 表格：行 = 1–12 次，列 = @10、@9.5 … @6，格子里是 e1RM × 表值、向下取整到 2.5 kg（lb 设置下换成 lb、取整到 5 lb）。左右滑动，「次数」列固定，行间隔底色。
- 这个主项没有 e1RM，或选「%」：格子里写百分比（`86.3%`），大字写 `100%` + 小字 `1RM`。
- 表值直接用两端现有的扩展版 RPE 表（spec 106），不复制一份。
- 页面上不放说明文字。

## 数据来源（工程约束）
- 只用学员端现有的计划详情、动作库元数据、学员资料（登记 1RM、单位）与现有 e1RM 数据。不新增接口、不改后端。
- 已练完的周取实际记录（现有学员端组记录），其余周取处方。
- e1RM 用打开弹层时学员当前的值（与训练页预填同一来源），整份计划的「约」都按这一个值算。历史重量预填开关（`HISTORY_WEIGHT_PREFILL_ENABLED`）保持关闭，本功能不依赖它。
- 计算放在纯函数里（输入：计划、动作元数据、当前 e1RM、登记 1RM、单位、当前周；输出：每行每周的状态、文字、比例、是否金色、跳转的 day id），UI 只负责画。
