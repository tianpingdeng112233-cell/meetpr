## 已拍板（引用即约束，不重议）

1. 数字面板改为「左侧数字区 + 右侧一列四个功能键」：加一组 / 一键改向上 / 一键改向下 / RPE。
2. 删除「下一项」。面板开着时，点同一天任意一个可编辑格子直接切过去，不需要先收起。
3. 「收起」改为数字区右上方悬浮的收起键盘图标；点遮罩以外的页面空白处行为不变（沿用 105 §6「收起不撤回」）。
4. 一键改：把当前格的值套到同一动作里上方（或下方）所有组的同一字段，只改这一个字段；已经存过的组也改，改过的重量照 107 显示「原 X」。
5. RPE 键：光标跳到本组强度格，面板顶部出一排快选；RPE 模式九格 6、6.5、7、7.5、8、8.5、9、9.5、10，RIR 模式六格 0–5。点一下即填入。
6. 热身组不放在键盘上：动作展开区组表第 1 组上方一行「＋ 加热身组」。每次点在已有热身组之后、第 1 组之前插一行，最多 5 组。
7. 热身组不计容量、e1RM、PR、当天进度；教练端不显示；不能拍视频（没有拍摄按钮）。
8. 不做：记录左右、kg/lbs 切换键、递减组键、热身自动计算。

## 界面（转写自定稿）

配色、字号、圆角一律用两端现有 token 与 107 / 105 的组件，不新增颜色。

### 动作展开区（107 A1/A2 的展开区，增改如下）

- 组表最上方新增一行文字按钮「＋ 加热身组」（强调色 13pt 半粗，左对齐，行高 44）。已有 5 组热身组时变为灰色不可点，文案「热身组最多 5 组」。
- 热身组行排在第 1 组之前：组号位显示「热」（强调色、粗体）；重量 / 次数 / RPE 三格与普通组相同；**行尾没有拍摄按钮**（留同宽空位，三格与下方各组左右对齐）。
- 新加的热身组默认值：有上一个热身组就抄它的重量和次数；第一个热身组重量为空、次数抄第 1 组。RPE 为空。加完后光标自动落在这一行的重量格、面板打开。
- 动作行的「组×次」摘要、进度、按计划判断、长按完成今天的计数**都不算热身组**。
- 热身组的删除方式与额外组相同。

### 数字面板（`allDay` 形态）

- 顶部一行上下文：「{动作名} · 第 n 组 · 重量|次数|RPE|RIR」，热身组写「热身第 n 组」。一键改后在末尾追加「· 已改下方 2 组的重量」（或「上方」；没有可改的组时「· 下方没有组了」），下一次按键清除。
- 主体左右两栏：
  - 左栏（约 3/4 宽）：3×4 数字键，末行「. ｜ 0 ｜ 退格」。次数格与 RIR 格小数点禁用。
  - 右栏（约 1/4 宽）四个等高功能键，自上而下：「加一组」、「一键改 / 向上」（两行，第二行小字次要色）、「一键改 / 向下」、「RPE」（表头为 RIR 时文案为「RIR」）。键高与数字键相同（52），底色比数字键深一级（现有 raised 色）。光标在强度格时「RPE」键为选中态（淡强调底 + 强调色描边与字）。
- 原底部「收起」与「下一项 →」整行删除。
- 收起键：面板上沿右侧、贴面板外悬浮，48×44 圆角 12，键盘加向下箭头图标，无文字（无障碍名「收起键盘」）。
- RPE 快选条：仅在光标位于强度格时出现，位于上下文行与数字键之间；一行等分（九格或六格），格高 44，选中值为强调色实心。

### 交互细节

- 换格：点别的格子时，先按 105 §6 结算当前格（合法则保留、非法或空回到上一个合法值），再切到新格。切换时页面把新格所在行滚到面板上沿之上（沿用现有滚动避让）。
- 加一组：光标在热身组上 → 加热身组（同 §6 规则）；否则加额外组（沿用现有「＋ 加一组」，默认抄最后一组的重量与次数，上限 10 组），光标落在新组重量格。
- 一键改范围：热身组与热身组之间互改；正式组（处方组 + 额外组）之间互改；两类不互相影响。当前格为空（重量 / 次数）时一键改不生效；RPE / RIR 为空时可把下方 / 上方清空。
- 一键改写入走与手动逐格修改完全相同的保存路径（本地草稿 → 现有「待同步」队列），不新造写服务器的时机。
- 只读日（以前的周、预览周、已结算只读）不出面板，也不显示「＋ 加热身组」。

### 保存

- 热身组行写入时带 `is_warmup: true`（后端 068）；其余与额外组同路（含离线待同步、撤销窗口）。
- 长按「完成今天」：重量为空的热身组不保存（丢弃该行），有重量的照常保存。
- 读取当天记录时按 `is_warmup` 把热身组排到第 1 组前，按 `set_index` 升序。
