# 099 — 开屏动画：图标起势，拉远成完整 logo

- **状态**: Ready（2026-11-02 /grill 两轮共识「确认」）。UI 卡等屏幕稿与 logo 矢量「定稿」后再派。
- **范围**: 安卓 RN 与 iOS 原生同批派卡、同批验收（meetpr-rn 仓 `specs/099-launch-animation/SPEC.md` 为同一文件的镜像）；零 backend。
- **级别 / 节奏**: T2 / P1。
- **与 spec 082 的关系**: 082 定「只留反馈和奖励、删装饰」。开屏动画是 082 之后**唯一**获准的新增例外，理由是它与冷启动加载并行、本身兼做加载反馈，不额外制造等待。iOS 仓 082 SPEC 已补一行指向本文件。

## 现状（已核实，2026-11-02）

- **iOS**（release/1.0 @a59c7a29）：`Info.plist` / `GlobalInfo.plist` 的 `UILaunchScreen` 只配了 `UIColorName = AccentColor`，即整屏红 #E5221E、无 logo（不在品牌规范内）。冷启动后依次出现：`Session.state = .authenticating` 时的转圈 +「正在验证登录」（`RootView.routedContent`）→ 聊天上下文激活时的空 `ProgressView`（`coachRoot` / `studentEntry`）→ 首页。
- **安卓 RN**（main @64eeb1f）：`expo-splash-screen`，底色 #F5F6F8，图片 `assets/images/splash-icon.png` 是建仓时的 1×1 占位图，实际是空白灰屏；`_layout.tsx` 在字体加载完即 `hideAsync()`，此时 session bootstrap 可能仍在进行。无过渡。
- **品牌真源**: 两仓 `docs/brand/README.md`——纸底 #F5F6F8、金盘 #D97706、「片里的折线」图标。完整 lockup（深蓝底板 MEETPR + 圆盘 + 标语 + 短线）**仓里没有矢量源**，本 spec 由设计侧重绘后入 `docs/brand`。

## 定义

- **冷启动**: 进程从零启动。从后台切回（热启动）不播。
- **首屏就绪**: 未登录 → 登录页可交互；已登录 → 教练根 / 学员根视图已渲染、不再有全屏转圈（含聊天上下文激活完成）。各 tab 内部自己的数据加载（骨架屏等）不算在内。

## 变更

1. **系统启动屏**: 两端改为纯色 #F5F6F8、无图，浅色与深色外观同色。
   - iOS：新增独立命名色（不改 `AccentColor`，它另有用处），两份 plist 都改。
   - 安卓：splash 图换成透明 / 空白；深色配置同色。Android 12+ 若系统强制显示图标导致静态图标先闪一下，要么消除，要么在 JOURNAL 记录为已知差异并附截图。
2. **开屏动画**（冷启动必播，已登录 / 未登录都播；全程纸底 #F5F6F8，深色模式也不变）。总长 1.2s，无触感、无声音：
   - 0–0.7s 图标段：圆盘落定 → 折线走平后拐头冲上去 → 圆点压在线头上。
   - 0.7–1.2s 拉远段：镜头拉远，圆盘归位到 lockup 中，显出完整 logo：深蓝底板白字 MEETPR、圆盘、英文标语「All about powerlifting」（所有语言版本都是英文原句）、标语下金色短线。
   - 段内具体关键帧与缓动以定稿屏幕稿为准；本条的分段与总长是硬约束。
3. **加载**: 动画与 session 恢复、首屏加载**并行**。
   - 1.2s 时首屏已就绪 → 整个开屏层 0.3s 淡出，露出首屏。
   - 未就绪 → 停在最后一帧，标语下的短线变成不定进度的加载线（一小段左右往返），不加文字；就绪后 0.3s 淡出。
   - 现有「正在验证登录」转圈与聊天初始化空转圈去掉（被开屏层覆盖期间不再需要；就绪定义见上）。
4. **减弱动态效果**（iOS「减弱动态效果」/ 安卓移除动画）开启时：直接显示最后一帧，加载线照常动，就绪后淡出。
5. 网络失败、离线、token 失效等异常路径沿用现有处理（开屏层在 session 落定为未登录或已登录后即视为可退出），本 spec 不改。

## 验收清单

1. 两端冷启动（已登录学员、已登录教练、未登录各一次）：纸底开屏 → 图标段 → 拉远显出完整 logo → 淡出进对应首屏；全程没有红屏、灰白空屏、「正在验证登录」、空转圈，也没有登录页一闪。
2. 系统启动屏与动画第一帧之间看不出切换（同色、无图标跳动）；深色模式下同样是纸底。
3. 弱网（模拟器网络限速）冷启动：动画播完停在最后一帧，短线变为往返加载线；就绪后淡出。
4. 从后台切回不播动画。
5. 开启减弱动态效果：直接最后一帧 + 加载线。
6. 带历史的老用户从现网版本升级后第一次打开：动画正常，进入的首屏与升级前一致。
7. 两端单测全绿；iOS 在 `iPhone 17e`、安卓在模拟器亲验第 1–5 条，交录屏。

## 测试 seam

- 两端各抽一个纯函数 / 小模型：输入「动画已播完」「首屏已就绪」「减弱动态效果」，输出开屏阶段（播放 / 加载线 / 退出 / 已移除）。先写这组状态表测试再接 UI。
- RN：复用 `src/analytics/__tests__/root-layout.test.tsx` 所在的根布局测试，补「首屏就绪前开屏层在、就绪后移除」。
- iOS：AppShell 现有测试 target 内补同样的阶段表测试；`RootView` 不再渲染 `validatingSession` 文案的断言（若无现成 seam，在 JOURNAL 记为发现）。

## Out of Scope

- 热启动、从通知或深链打开时的额外过渡。
- 各 tab 内部的数据加载样式（骨架屏、局部转圈）。
- 异常路径（离线、token 失效）的 UI 改动。
- App 图标本身、`AccentColor` 的其它用途。
- 网页端与官网。
