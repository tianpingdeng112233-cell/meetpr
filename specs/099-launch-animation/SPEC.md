# 099 — 开屏动画：字标入场 + 单向加载线

- **状态**: 定稿（2026-11-27 David 在可交互稿上定稿并要求实装）。取代 2026-11-02 的「图标起势、拉远成 lockup」方案，旧分镜作废。
- **范围**: 安卓 RN 与 iOS 原生同批实装、同批验收（meetpr-rn 仓 `specs/099-launch-animation/` 为本目录的镜像）；零 backend。
- **级别 / 节奏**: T2 / P1。
- **参照稿**: [`reference/splash.html`](reference/splash.html)（单文件，浏览器直接打开；`?t=1.2` 冻结在某一秒）。关键帧、缓动、几何以它的 `render(t)` 为准，两端各有一份同构的纯函数。
- **与 spec 082 的关系**: 082 定「只留反馈和奖励、删装饰」。开屏动画是 082 之后**唯一**获准的新增例外，理由是它与冷启动加载并行、本身兼做加载反馈，不额外制造等待。

## 定义

- **冷启动**: 进程从零启动。从后台切回（热启动）不播。
- **首屏就绪**: 未登录 → 登录页可交互；已登录 → 教练根 / 学员根视图已渲染，途中的全屏转圈（session 恢复、组同步宿主、e1RM 迁移门、绑定门、聊天上下文激活）都已结束。各 tab 内部自己的数据加载不算在内。

## 画面（1080 宽画布，按屏宽等比缩放，以屏幕中心为锚）

1. **背景**: 暖色到纸白的竖向渐变图铺满全屏，上叠一层随时间略增强的暖色/白色渐变，字标背后有一圈淡橙色光晕。浅色与深色外观同一套，不随系统变暗。
2. **字标**: 2026-11-27 定稿字标（`docs/brand/meetpr-wordmark-final.svg`），宽 832，中心在屏幕中线上方 78。
3. **标语**: 「Meet Every PR Together」，所有语言版本都是英文原句；粗体 44，色 `#101726`，中心在中线下方 99。
4. **加载线**: 标语下方，轨道宽 196、橙色短条宽 57（`#E6681E`），中心在中线下方 161。

## 时间轴（总长 1.2s，无触感、无声音）

| 时刻 | 发生什么 |
|---|---|
| 0–0.63s | 字标淡入，同时上移 18 → 0、放大 0.968 → 1 |
| 0–0.70s | 光晕与字标投影渐强 |
| 0.23–0.83s | 标语淡入，上移 14 → 0 |
| 0.43–1.20s | 加载线出现，短条**从左到右扫一趟**，停在右端 |

## 加载与退出

- 动画与 session 恢复、首屏加载**并行**。
- 1.2s 时首屏已就绪 → 整个开屏层 0.3s 淡出。
- 未就绪 → 画面停在最后一帧，短条在右端淡出，再从左端淡入往右扫，循环到就绪为止；**全程不往回走**。就绪后 0.3s 淡出。
- 首屏提前就绪也要把 1.2s 播完。
- 冷启动期间的「正在验证登录」文案删除；途中的全屏转圈被开屏层盖住。退出登录等非冷启动场景仍显示原有转圈。
- 首次安装的隐私同意弹窗、安卓的更新提示都等开屏层离开后再出现。

## 系统启动屏

- **iOS**: `UILaunchScreen` 用烘焙好的动画第 0 帧背景图（背景 + 0 秒时的暖色叠层）铺满，底色纸白；与动画第一帧无缝衔接。
- **安卓**: 系统启动屏只能是纯色，保持纸白 `#F5F6F8`、无图标；动画开头 0.15s 把渐变背景淡入，避免突变。

## 减弱动态效果

iOS「减弱动态效果」/ 安卓「移除动画」开启时：直接显示最后一帧，加载线照常循环，就绪后淡出。

## 已知差异（接受）

- 参照稿标语字体是 Inter；两端不为一行字打包新字体，用系统粗体（iOS SF、安卓 Roboto）。
- 安卓不做标语字距的细微收紧动画，直接用终值；字标投影用固定值，不随时间变化。
- 参照稿是 9:16 舞台，全面屏上下会露底色；两端改为背景铺满全屏，内容位置仍按屏幕中心计算。

## 验收清单

1. 两端冷启动（已登录学员、未登录各一次；教练端 App 暂缓，见 2026-11-27 「首发只上学员端」）：暖色开屏 → 字标与标语入场 → 加载线从左扫到右 → 淡出进对应首屏；全程没有红屏、空白屏、「正在验证登录」、全屏转圈，也没有登录页一闪。
2. 字标、标语、加载线的位置与大小和参照稿在同尺寸视口下一致（iOS 逐项量过）。
3. iOS 系统启动屏与动画第一帧之间看不出切换；深色模式下仍是同一套浅色画面。
4. 首屏未就绪时，短条循环单向扫，从不往回走；就绪后淡出。
5. 从后台切回不播。
6. 开启减弱动态效果：直接最后一帧 + 加载线。
7. 带历史的老用户从现网版本升级后第一次打开：动画正常，进入的首屏与升级前一致。
8. 两端单测全绿。

## 测试 seam

- 两端各一个纯函数：输入「动画已播完」「首屏已就绪」「减弱动态效果」「退出已完成」，输出开屏阶段（播放 / 加载 / 退出 / 已移除）。
- 两端各一个纯时间轴函数 `frame(t)`：断言首末帧、关键时刻，以及「短条可见时只向右移动」。
- RN：`LaunchSplash` 组件用假时钟验证「未就绪不退、就绪后只退一次、提前就绪也播完、减弱动态直接退」；根布局测试补「session 恢复期间开屏层在、同意弹窗不出，就绪后反过来」。
- iOS：`Session.hasBootstrapped` 在恢复落定后才为真。

## Out of Scope

- 热启动、从通知或深链打开时的额外过渡。
- 各 tab 内部的数据加载样式（骨架屏、局部转圈）。
- 异常路径（离线、token 失效）的 UI 改动。
- App 图标本身；App 内其它位置换定稿字标（另见 wordmark-final 分支）。
- 网页端与官网。
