## 已确认行为

### 1. 登录页：邮箱密码在上，第三方登录在下

- 顺序：邮箱、密码、Sign in → 分隔 "or" → 第三方登录按钮。iOS 为 Apple、Google；安卓为 Google。
- 注册页若展示第三方入口，同一顺序。其余文案、校验、找回密码入口不变。
- iOS 上 Apple 与 Google 按钮保持同等显著度。

### 2. W#D# 的 D 是"本周第几练"

- D = 该训练日在所属周内的序号，从 1 起，按该周训练日的既有先后顺序（`day_of_week`、再 `sort_order`）计数；已完成的也占号。
- 例：一周的训练日落在星期二、四、六、日，显示为 D1、D2、D3、D4（现状显示 D2、D4、D6、D7）。
- 所有出现 W#D# 或 D# 的学员端位置一致：Today 页头、训练页页头、周条小卡、计划周列表、训练历史、补录、聊天里的训练卡片。教练端凡展示学员训练日序号处同一口径（安卓教练端学员详情现状已是序号）。
- `day_of_week` 字段本身不变，继续决定顺序与教练推荐日期；本项只改展示。
- 教练在一周中间补加或后移训练日后，序号随顺序重排，这是预期行为。

### 3. Today 的 Meetday 卡与体重卡可点

- 有无数据都可点。Meetday 卡进 Profile 的 Meet / notes 编辑页；体重卡进 Basic information 编辑页。
- 保存或取消后回到 Today，卡片立即反映新值。卡片外观不变，补上按压反馈与无障碍的按钮语义。

### 4. 删除 Plan summary；周条可左右翻周

- 训练页下方的 Plan summary 区块（含每周折叠列表）删除。
- 顶部周条成为查看其他周的唯一入口：可左右翻到计划内的任意一周，默认停在当前周；翻到其他周时可点选那一周的训练日查看安排。
- 周条上"选中的日子"与"今天该练的日子"分开表示（走查问题 D-29）：选中框跟随点选；当前训练日用独立标记。具体样式以设计稿为准。
- 本项与 D-29 同一份设计稿，定稿前不派卡。

### 5. 删除训练页的 e1RM 祝贺横幅

- 只删训练页顶部这条横幅。PR 事件照常记录；Progress 页的曲线、记录点、来源详情不变。
- 原本会在横幅展示的未确认 PR 事件，在同一时机静默标记为已确认，不堆积。

### 6. 训练提醒默认日取教练计划

- 首次打开训练提醒、且用户从未保存过自定义星期时，默认勾选 = 当前这一周各训练日"教练推荐日期"所在的星期。
- 没有已发布计划：回落到档案里的训练日；仍没有：一、三、五。
- 用户保存过的设置一律不动；计划后来变化也不自动改用户已保存的星期。

## 存量数据与升级

- 六项都不改服务器数据、不改本地持久化结构。
- 带历史的老用户升级后的第一屏：Today 与训练页的 W#D# 由星期槽位变为序号，属预期变化；已完成进度、当前训练日、休息计时、草稿不受影响。
- 已保存的训练提醒设置保持原样（§6）。

## 设计定稿（2026-10-02，David 逐张确认）

设计稿是布局、层级、间距的参照，不是像素与品牌素材的来源；颜色字号用各端现有 token。画布（私有链接，实装方打不开，以下转写为准）：`https://claude.ai/artifact/H9X4VhGABqrBNLxcmdgrsi`。稿中的示例数据是虚构的。

### §1 登录页

自上而下：wordmark → 大标题 → EMAIL 输入 → PASSWORD 输入（带显示/隐藏）→ 主按钮 Sign in → 一行两个文字链接（左 Create account，右 Forgot password?）→ 分隔线中间一个 "or" → 第三方登录按钮，描边的次要按钮样式，整行宽 → 页面底部法律文案。iOS 的第三方按钮为 Apple、Google 两个，上下排列、同等尺寸；安卓只有 Google。

### §4 训练页周条（含 D-29）

页头不变（W#D# 标题、三个圆形按钮、Training history 文字入口）。其下为周条区块，三行：

1. 换周行：左箭头（44pt 命中区）｜居中 "W{n}" + 状态胶囊 + "已完成数 / 总数"（等宽字）｜右箭头。状态胶囊：当前周 "Current week"（淡金底）；未来周 "Upcoming"（中性底）；已过的周 "Completed" 或进度本身。第一周左箭头、最后一周右箭头置灰。
2. 训练日行：该周每个训练日一格，等宽排成一行。每格三层：状态图形（已完成 = 绿色对勾；未完成 = 空心圆）、"D{序号}"、日期（如 "Mon 10/5"）。
   - **选中**的日子：深色 2pt 粗框、白底。选中框跟随点选。
   - **今天该练的日子**（当前训练日）：整格淡金底色、日期用金色加粗、状态图形为金色空心圆。与选中是两种手法，可以同时出现（淡金底 + 深色粗框）。
3. 周数指示：一排小点，每周一个，正在看的那一周是拉长的深色点；不在当前周时，当前周那个点用金色。计划超过 8 周时不画小点（换周行里的 "W{n}" 已足够）。

翻到其他周时：页头右侧三个圆形按钮的位置换成文字链接 "Back to today"（点了回到当前周并选中当前训练日）；标题显示所选那天的 W#D#。周条下方卡片展示所选那天的安排：教练推荐日期一行、训练日名称、"N exercises total · M sets"、逐个动作行（名称 + 重量 × 次数）；未来的训练日是只读预览，没有开练按钮，底部一句说明当前该练的是哪一天。已完成的训练日沿用现有的已完成展示。Plan summary 区块整体删除。

### §7 Ask coach 选组（走查 D-22）

一页完成，替代现在的"选组列表 → 写留言"两步：

- 页头 "Ask coach" + 右上关闭。
- 提示语一行："Which set is this about?"
- 每个动作一张卡：动作名只出现一次，右侧 W#D#；下面是该动作各组的小格，三列等宽网格（多于三组换行）。每格三行：`Set n`、`重量 × 次数`、状态（`Logged · RPE x` / `Logged · video` / `Planned`）。选中的格：深色粗框、白底。
- "Your question" 多行输入框（占位："What do you want your coach to look at?"）。
- 底部一行小字复述将发送的内容（"Sends Set 2 of <动作名> with your question"）+ 主按钮 "Send to coach"。
- 训练页的 Ask coach 与聊天页 "+" 两个入口都用这一页。

### §8 聊天里的训练卡（走查 D-23）

学员发出的带训练组的消息是**一个**气泡：上方是学员写的话，正文字号，和普通消息一样显眼；下方是嵌在气泡里的附件行（浅色内嵌块）：有视频时左侧一个播放图形的方块，中间两行（动作名；`Set 2 of 3 · 50kg × 5 · RPE 8`），右侧 chevron；点附件行进入现有的详情 / 播放。气泡下方一行 `时间 · Delivered`。没有写话时只显示附件行。教练端看到的同一条消息用对方气泡的配色，结构相同。

### §9 组录入页的视频行（走查 D-24）

**范围：只用于训练页组录入里学员自己录完或选完视频后的回看。教练反馈、聊天、打点所用的独立全屏播放页保留不动。**

- 没有视频：维持现状（"Video" 标签 + Record + Photos）。
- 有视频：一块深色圆角的原地播放器。画面在上，底部一行控件从左到右：播放/暂停、进度条（下方左右两端是已播 / 总时长）、倍速按钮、放大按钮。倍速按钮平时只显示当前倍速（如 `1×`），点击后向上展开四档列表（2× / 1.5× / 1× / 0.5×），选中项高亮，选完收起。放大按钮在最右下角。
- 播放器下方一行：左侧状态（Sending / Delivered to coach / 失败与重试），右侧 Replace、Delete 两个按钮，同一行、文字不折行。
- 放大：播放器在当前页面上铺满整屏，不跳转到别的页面；视频占满屏幕，顶部半透明条显示动作名与组信息，底部半透明条是同一组控件，最右下角的按钮变为缩小。系统返回先缩小、再走原有返回。缩小后回到原位继续播放，进度与倍速保持。

### §10 休息时间说明（走查 D-14）

首次出现的说明改为底部弹层：标题 "Rest time follows your RPE"；一句说明；一个三行对照表（左列条件、右列时长）：`RPE below 7 → 2 min`、`RPE 7 to below 9 → 3 min`、`RPE 9 or above → 4 min`（数值取各端现有的默认规则，不在此另立）；一句 "If your coach set a rest time for a set, that one is used instead."；主按钮 "Got it"；其下文字链接 "Change in Profile → Rest between sets"。出现时机、只出现一次的规则不变。中文文案同步更新。

## §4 修订：周条改为 7 天日历格（2026-10-03 David 定稿）

来源：David 真机复验反馈"一周 4～5 次训练，看不出哪天休息"。画布板「1c 周条 · 7 天日历格」。替换原 §4 第 2 行"训练日行"的写法，其余（换周行、周数小点、选中与当前训练日两种标记、翻周、Back to today、未来训练日只读预览）不变。

- 训练日行改为**连续的日历格**：起点 = 该计划周第一个训练日的教练推荐日期；格数 = max(7, 该周最后一个训练日推荐日期 − 起点 + 1)。正常情况恰好 7 格；教练后移导致跨度超过 7 天时多出的格子照排，周条可横向滚动。
- 每格自上而下：星期缩写（如 Mon）→ 状态图形 → D 序号 → 单行短日期（如 10/5）。训练日格的选中 / 当前训练日 / 已完成 / 未完成样式沿用定稿。
- **休息日格**：该日没有训练日。宽度约为训练日格的 0.7，浅灰底，显示星期、"Rest"、日期，不可点，读屏为"<星期> <日期>, rest day"（中文：休息日）。
- 同一天不会有两个训练日（David 2026-10-03 确认），不为此做特殊界面。
- 序号仍走卡 A 的序号入口；`day_of_week`、推荐日期、完成推进不变。
- 文案："Rest" / 中文"休"。
