## 术语

**辅助项**：动作库里类型为 `accessory` 的动作，即既不是主项（`main_lift`）也不是主项变式（`main_lift_variation`）。判定只看动作库的 `exercise_type`，与教练在计划里勾的"主项"标记（`is_main_lift`）无关。已写入仓根 `CONTEXT.md`。

## §1 辅助项记录卡

**何时出现**：训练页记录态下，当前轮到的动作是辅助项、且该训练日可编辑（是当前训练日）时，hero 卡显示为"辅助项记录卡"。当前动作是主项或主项变式时，hero 卡与现状（含 spec 086）完全一致。只读预览、已完成详情不出现本卡。

**结构**（自上而下，细节以屏幕稿为准）：

1. 动作名 + `Ask coach`（现状）。
2. 教练备注淡金块（spec 086：有动作备注才出现）。
3. 行内表格，每个计划组一行，列为：组号｜上次｜重量｜次数｜RPE｜✓。
   - **组号**：可点，打开原来的完整录入页（该组），可拍视频、从相册选、标记失败、用 RPE 刻度。该组有视频时组号旁有视频标记。
   - **上次**：这个动作上一次训练里同一组序的实际记录（`重量 × 次数`），没有则 `—`。点它把数值填进本行的重量与次数。
   - **重量 / 次数**：行内输入框，预填教练处方；单位跟随学员的单位偏好。处方没给具体重量（纯 RPE / RIR 处方、区间处方）时重量框为空，灰字占位显示上次的重量。自重组（组级标记为自重）重量框显示 `BW`、不可填、按 0 记录。
   - **RPE**：小输入框，选填。灰字占位显示教练预设（处方是 RIR 时占位显示 `RIR n`，填法与完整录入页一致，写入的仍是 RPE）。
   - **✓**：见 §2。
4. 表格下一行常驻提示：`Tap a set number to record video or mark it failed`（中文"点组号可拍视频或标记未完成"）。
5. 主按钮「全部按计划完成」（英文 `Complete all as planned`），见 §3。全部组都已记录后主按钮消失，卡片切到下一个动作。

处方行、上次成绩行、`Log this set` 与摄像机按钮在本卡里不出现（信息已并入表格）。组级 `coach_note` 的小灰字块：自重标记不再单独显示（已体现在 `BW`）；其他内容（旧导入的节奏说明）在对应行下方以小灰字显示。

下方"分动作组表"维持现状不动。

## §2 逐组点 ✓

- 点 ✓ = 按该行当前的重量、次数（以及学员填了的 RPE）写入一条普通记录（`completed: true`，`failed: false`），与完整录入页"Complete set"写入的是同一种记录；写入日期、PR 判定、读回后的显示全部走现有路径。
- 能点的条件：重量与次数合法（规则沿用现有校验；辅助项重量下限 0）。不合法时 ✓ 置灰，对应输入框标红。
- 写入中该行 ✓ 显示进行态、不可重复点；失败时恢复未记录并用现有的保存失败提示。
- 记录成功后：该行变为已完成样式（绿色 ✓，数字仍可改——改后再次点 ✓ 覆盖写入），并起休息计时（§4），除非它是这个动作的最后一个未记录组。
- **取消**：对已完成的行再点一次 ✓ = 把这组写回未完成（`completed: false`，`failed: false`，重量次数保留）。界面回到未记录样式。后端各处统计、PR 判定、进度都跳过这种行（已核实 `exercise-stats` / `pr-detection` / `session-progress`）。已带视频的组不能取消：点 ✓ 时提示先到完整录入页处理视频。
- 行的顺序不强制：可以先记第 3 组再记第 1 组。
- 记录第一组即视为"已开始"（现有口径：已有 ≥1 组真实记录）。

## §3 全部按计划完成

- 一次把这个动作里所有"未记录且重量次数合法"的行按行内当前数值写入，逐条提交；RPE 只写学员填了的。
- 重量为空的行跳过；结束后若有跳过或失败的行，卡片留在这个动作，并提示 `N sets still need a weight`（中文"还有 N 组需要填重量"）或现有的保存失败提示。
- 不起休息计时。
- 全部写完后卡片切到下一个动作。

## §4 辅助项休息时长

- 时长优先级：教练给这组设的 `rest_seconds` → 学员的"辅助项休息"设置 → 默认 60 秒。主项的按 RPE 分档规则不用于辅助项。
- Profile → Rest between sets 页新增一行 `Accessory exercises`（中文"辅助项"），可调 30 秒–5 分钟，步进 15 秒，默认 `1:00`；与现有"自动 / 自定义"两种模式无关，始终可调。
- 存储：在现有休息计时偏好里追加一个字段；**旧用户没有这个字段时按 60 秒**，现有的主项设置原样保留。
- 休息计时的界面、通知、+30 / −30 / Skip 全部沿用现状。首次出现的"休息时间跟 RPE 走"说明弹层只在主项场景出现，辅助项不弹。

## 存量数据与升级

- 进行到一半的训练日（部分组已用完整录入记过）：升级后已记的行显示为已完成，未记的行可继续用 ✓；带视频的组显示视频标记。
- 用旧包或 iOS 记录的辅助项组在本卡里同样显示为已完成，可改数字覆盖。
- 动作库里解析不到类型的动作（缓存缺失、自建动作被删）按**非辅助项**处理，走完整录入——宁可多点几下，不误把主项当辅助项。
- 没有组数、只有备注的辅助项维持现状，不出现本卡。
