# spec 111 — 组间休息倒计时：悬浮圆环（两端）

- **状态**：Ready（2026-11-17 /grill 三轮共识；屏幕稿 2026-11-17 David 逐张改定 https://claude.ai/artifact/PsiBtNYQy8Qu4UX5GDGF3z ；可交互稿 https://claude.ai/artifact/3eQK3vRhydL3ZXP82X4Yt9 ，同日 David 指示「推进开发」）。
- **级别 / 节奏**：T2（新的用户可见行为，两端客户端）；P1。iOS（`release/1.0`）与安卓 RN（`main`）同批派卡、同批验收。零后端。
- **前置**：spec 107 表格模式已把组间休息整体下线（代码保留），并写明「新触发方式另立 spec」——本 spec 即是。

## 问题

表格模式不逐组打勾，App 不知道学员哪一组刚做完，原来「打完一组自动开始休息」没有触发点，所以 107 把休息计时下线了。学员组间要靠自己看表。

## 已拍板（David 2026-11-17）

1. 触发：**手动**。轻点圆环开始倒计时，长按进休息设置。
2. 入口：训练页一个**悬浮圆环**，默认右下角、「长按 · 完成今天」上方；可拖到左侧或右侧贴边，记住位置。
3. 计时中轻点：展开成**屏幕正中的圆盘**，盘内 `-15s` / 结束 / `+15s`，顶部齿轮进设置。
4. 走完：圆环上直接写「休息结束」，约 3 秒后回到待机，不自动重开。
5. 提醒：最后 10 秒每秒震一下；结束响一声提示音。设置里「震动」「提示音」两个开关，默认都开；手机静音时提示音不响、震动照常。
6. 离开 App：恢复 iOS 锁屏 / 灵动岛倒计时、安卓通知栏倒计时（代码都在）；结束时给一条带声音和震动的通知（同样受两个开关控制）；后台不做逐秒震动。
7. 时长：教练给了休息时长用教练的；否则按「当前动作」是主项还是辅助项取学员设的固定时长，默认主项 3:00、辅助项 1:00。不再按 RPE 分档。
8. 设置也是**圆盘**，时长用苹果式**上下滑动滚轮**选；**学员第一次打开训练页直接弹出设置圆盘**，收起后才是待机圆环。

## 屏幕结构（转写自定稿画板，Codex 打不开外链，以本节为准）

配色一律用两端现有 token（深 / 浅两套），不新增颜色。下文「金」= `accent`（深 #F5A623 / 浅 #D97706），「主按钮」= 现网「完成今天」按钮的底色与字色，「浮层底」= `surface2`，「按钮底」= `surface3`，「描边」= `borderStrong`。尺寸单位 pt。

### R1 待机圆环
- 64×64 圆，底色「按钮底」，1.5 金描边。内容竖排：计时器图标（20，金）+ 下方时长文字（12 粗，等宽数字），显示**这次点下去会倒数多久**（随当前动作变）。
- 位置：默认距右 16、底边在「完成今天」按钮上方 12；左右贴边各留 16。上下可拖，不得盖住顶部周条与底部「完成今天」按钮。
- 首次提示（只出现一次，见「首次」）：圆环旁一个浅底深字气泡「轻点开始休息 / 长按设置时长」，圆环在右时气泡在左、在左时在右。

### R2 计时中
- 同一个 64 圆：外圈 4 宽进度环（底环「描边」色，进度金，从 12 点顺时针减少），中间剩余时间 17 粗等宽，如 `2:41`。
- 最后 10 秒数字变金。

### R3 展开圆盘（计时中轻点圆环）
- 全屏 60% 黑罩；屏幕**正中**一个 280 直径圆盘，底色「浮层底」，外圈 8 宽进度环（同上配色）。
- 盘内自上而下：齿轮按钮（44 点击区，图标 20，距盘顶 14）→「暂停卧推 · 休息 3:00」（12 次要色，动作名 + 本次总时长）→ 剩余时间大字（60 粗等宽，最后 10 秒变金）→ 三个 56 圆按钮横排、间距 12：`-15s`（按钮底 + 描边）、`结束`（主按钮配色）、`+15s`。
- 盘下 16：一行「点空白处收起，倒计时继续」（12）。
- 点黑罩收起；倒计时不受影响。

### R4 休息结束
- 64 圆，4 宽金色实心外环（走满），中间两行「休息 / 结束」（13 粗）。约 3 秒后自动回 R1；期间轻点也直接回 R1。不用绿色、不用勾、不加旁边气泡。

### R0 / R5 设置圆盘（首次打开自动弹出；之后长按圆环或点 R3 齿轮进入）
- 全屏 60% 黑罩；屏幕正中 340 直径圆盘（窄屏按屏宽 −12 等比缩小），底色「浮层底」，1 描边。
- 盘内自上而下：「休息设置」（14 粗次要色）→ 两个滚轮并排、间距 16：每个上方标题「主项」/「辅助项」（13），滚轮 112 宽、可视三格（每格 34 高），中间格有圆角 10 的高亮带，选中值 22 粗、上下相邻值 16 淡色 → 两个 48 圆形开关并排、间距 40：震动（手机振动图标）、提示音（喇叭图标），开 = 金底深色图标、关 = 按钮底 + 描边 + 次要色图标；圆下方小字「震动 · 开」「提示音 · 关」。
- 盘下 16：一行「上下滑动选时长 · 点空白处保存并收起」。
- 滚轮取值 0:30–10:00，每格 15 秒；点黑罩即保存。

## 行为

### 时长取哪个
- 「当前动作」= 学员展开着的那个动作；没有展开时取金底标出的那个（第一个未完成的）；全部完成时取最后一个动作。
- 当前动作教练给了休息时长 → 用教练的（上限沿用现有 900 秒）；否则主项用「主项时长」，辅助项用「辅助项时长」。主 / 辅判定沿用现有动作库分类（107 里「只影响预填来源」的那套）。
- 待机圆环上的时长随当前动作即时变化。计时开始后时长固定，改当前动作不影响这次倒计时。

### 操作
- 待机轻点 → 开始倒计时（R2）。
- 计时中轻点 → 展开 R3；R3 上 `±15s` 加减剩余（不低于 0，不超过 900 秒）；结束 → 立即回 R1，不响不震。
- 结束态轻点 → 回 R1。
- 任何状态长按（约 0.5 秒）→ 圆环轻微放大并轻震一下后打开设置圆盘；按到一半松手缩回，不触发任何动作。倒计时在设置打开期间继续走。
- 按住移动超过 8pt → 拖动，松手按圆心落在哪半屏吸到左 / 右边，纵向位置保留并限位。拖动不触发点 / 长按。位置按设备本地记住。
- 长按「完成今天」→ 若在计时，计时直接结束（不响不震，取消所有休息通知）。
- 切到别的 tab 再回来：倒计时照常走，回来显示同一剩余时间（按墙钟终点算，不靠前台刷新）。

### 提醒
- App 在前台：剩余 10、9…1 秒每秒震一次（震动开关）；到 0 时响一声短提示音（提示音开关），并震一次（震动开关）。
- App 在后台 / 锁屏：iOS 用现有 Live Activity 显示倒计时；安卓用现有通知栏倒计时（spec D-16），通知上的加时按钮改为 `+15s`。到 0 时发一条「休息结束」通知：提示音开关开才带声音，震动开关开才震动；两个都关仍出通知但静默。不做逐秒震动。
- 静音：提示音跟随系统静音；震动不受影响。

### 首次
- 「首次」按本设备上这个学员账号算（沿用现有按 studentId 存本地标记的做法），升级上来的老学员第一次进训练页也算首次。
- 首次进入可练的训练日 → 自动弹设置圆盘（R0）。点空白收起后保存设置，并在待机圆环旁出现一次首次提示气泡；学员第一次轻点或长按圆环后气泡消失，以后不再出现。

### 何时显示圆环
- 只在当天可练时显示（游标日与 107 §追加 1 放开的未结算日）。已结算日只读回看、休息日、没有计划时不显示。
- 底部数字面板（spec 105）弹起时圆环隐藏，收起后恢复。

### 设置存储与旧数据
- 设置全部存设备本地、按学员分开（与现有休息设置一致），不上后端。
- 升级照护：老学员本地若存过旧的「自定义三档」，主项时长取原中档（mid）；存过辅助项时长则沿用（超过 600 截到 600）；都没有就用默认 3:00 / 1:00。旧的「自动（按 RPE）」模式视同没设。震动、提示音默认开。
- 下线：按 RPE 自动分档、自定义三档、休息时长说明弹窗（RestTimerExplanation）、旧底部计时条。「我的 › 设置」里组间休息一行**不恢复**，设置只从圆环进。代码可删，旧存储键读一次迁移后不再写。

## 验收清单（iOS 用 `iPhone 17e`，安卓用自起模拟器；深浅两色各看一遍）

1. 全新学员第一次进训练页：先弹设置圆盘，两个滚轮显示 3:00 / 1:00，两个开关为开；滚轮上下滑能停在 15 秒整格；点空白收起后右下角出现待机圆环与「轻点开始休息 / 长按设置时长」气泡。
2. 再次进入训练页：不再弹设置盘，气泡在第一次点圆环后消失且不再出现。
3. 待机圆环时长：展开一个主项显示主项时长，展开一个辅助项显示辅助项时长；教练给了休息时长的动作显示教练的时长。
4. 轻点开始：进度环与剩余时间每秒更新；切去「教练」tab 30 秒再回来，剩余时间相差不超过 1 秒。
5. 计时中轻点：圆盘在屏幕正中，`+15s` / `-15s` 各点一次剩余时间对应变化，「结束」立即回待机；点空白收起后倒计时继续。
6. 最后 10 秒：数字变金、每秒一震；到 0 响一声（手机未静音）并震一次，圆环显示「休息结束」约 3 秒后回待机。关掉「震动」后重测无震动；关掉「提示音」后重测无声。手机静音时无声但有震动。
7. 长按圆环（待机与计时中各一次）：轻震并打开设置圆盘；按一下就松手不打开；R3 的齿轮也能打开同一个盘；计时中打开设置倒计时不暂停。
8. 拖动圆环到左边松手吸左；杀掉 App 重开仍在左。拖动过程不开始计时、不打开设置。
9. 计时中锁屏：iOS 锁屏 / 灵动岛显示同一倒计时；安卓通知栏显示倒计时，点 `+15s` 后回 App 剩余时间一致。到 0 收到「休息结束」通知，声音 / 震动跟随两个开关。
10. 计时中长按「完成今天」：计时结束、无提醒、无残留通知。
11. 已结算日、休息日、只读回看不显示圆环；数字面板弹起时圆环不挡输入。
12. 老用户升级：之前设过自定义三档（如 2:00/3:30/4:00）和辅助项 1:30 的账号，升级后第一次进训练页弹设置盘，显示 3:30 / 1:30；「我的 › 设置」里没有组间休息一行；训练页其他内容与 107 现网一致。
13. 繁体与英文各看一遍设置盘与 R3 文案不截断。

## 测试 seam（先红后绿）

- **iOS**：在 StudentKit 加一个纯模型（如 `RestRingModel`），用现有 `StudentKitTests` 先红后绿：时长解析（教练 > 主 / 辅设置；当前动作三种取法）、状态机（idle → running → done → idle；`±15` 上下限；结束；完成今天打断）、最后 10 秒的震动时刻表、首次标记与气泡、旧设置迁移（三种旧存储 → 新两档）。Live Activity 走现有 `RestTimerActivityControlling` 假实现断言 start / update / end 调用。
- **RN**：扩现有 `rest-timer-session.ts` 与 `policy.ts` 的单测（同上各条），设置迁移放 `rest-timer.test.ts`；手势用现有组件测试覆盖「轻点开始」「计时中轻点展开」「长按开设置」三条；通知模块的 `+15s` 与开关沿用 `rest-timer-notification.test.ts`。
- 界面以模拟器亲看为准，不加快照测试。

## Out of Scope

- 录完视频或改值后自动开始休息、逐组打勾。
- 安卓系统悬浮窗（浮在别的 App 上）。
- 整场训练总计时。
- 后台逐秒震动。
- 设置上云 / 跨设备同步；教练端看学员休息时长。
- 「我的 › 设置」里的入口。
