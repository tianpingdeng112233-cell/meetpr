### 一行缩略写法（David 2026-11-10「1A 2A 3A」，覆盖教练网页编辑器能写出的全部处方）

总规则：一行 =「组×次 ｜ 重量或强度」。连续几组完全相同就合并；不同就用「/」按顺序列出，相同的连在一起写「×几」；次数不同的几段用「·」隔开；太长折到第二行，不截断。练过之后这一行显示实际值（同一套写法），改过的数字强调色，没做满写「4/6」。单位跟随学员设置（kg / lb）。

| 处方（网页编辑器） | 一行显示 |
|---|---|
| N 组 × 次，统一重量 | `4×8  130` |
| 逐组重量 | `3×3  135×2 / 120` |
| 不同次数的几段（如 1×1 150 再 3×3 135） | `1×1 150 · 3×3 135` |
| 重量区间 | `4×5  100–110` |
| 次数区间 | `3×8–10  60` |
| AMRAP（次数「5+」） | `1×5+  100` |
| 自重 / 自重加负重 | `3×10  自重`、`3×8  自重+10` |
| 自选重量 + 强度 | `4×12  自选 · RPE 8` |
| 只写 RPE，逐组不同 | `4×12  RPE 6/7/8/8` |
| 只写 RPE，统一 | `3×5  RPE 8` |
| RPE 区间 / RIR | `3×5  RPE 7–8`、`3×10  RIR 2` |
| 百分比（1RM / e1RM 锚点，能换算） | `5×5  112.5 (75%)`；换算不了写 `5×5  75%` |
| 顶组百分比，顶组还没练 | `3×5  60% 顶组`；顶组练完后改显示算出来的重量 |
| 学员自加动作 | 动作名后加「· 自加」，显示实际值；没填的显示「未记录」 |

已拍板的三处：
1. **重量和 RPE 都写了**：每组 RPE 相同 → `4×5  100 · RPE 7`；各组 RPE 不同 → 行上只写重量，RPE 展开后看。（1A）
2. **只写 RPE、重量按「同动作同 RPE 同次数同序位」历史预填**：行上照教练原话写 `RPE 6/7/8/8`；预填重量只在展开区显示。（2A）
3. **同一天同动作排两行**：第二行不重复动作名，缩进。（3A）

本版不处理：热身组不做特殊区分，按普通组计数与显示；弹力带、组内休息（簇组）、渐进加重等进阶设置行上和展开区都不显示（David：这一版先不做）。

## 数据规则

- **预填优先级**（每组）：学员已记录的值 ＞ 教练处方值 ＞ （只写 RPE 时）后端 065 建议重量 ＞ 空。次数、RPE 同理（RPE 处方为空则空）。
- **动作完成小勾**：把该动作所有组按当前显示值写入（已存在的组记录更新，不存在的创建）；重量为空的组照样写（weight 为空）。取消小勾不删除记录。
- **长按完成今天**：先按上条写入所有未写过的组（含自加动作、额外组），再走现有完成接口；视频未送达时沿用现有等待逻辑。
- **教练端「按计划」**：某组实际值（重量、次数、RPE）与处方完全一致时，教练 App 的学员日详情 / 组卡片用「按计划」代替重复数字；不一致的照常显示实际值并标出与处方的差异（沿用现有差异样式）。处方为区间时落在区间内视为一致。
- **空重量**：所有显示重量的地方（学员历史、成长、教练端、聊天组卡片）显示「—」；e1RM 不计这组；导出 CSV 重量列留空。

## 长按完成：零必填（2026-11-10 David 追加）

学员在训练 tab 里**没有任何东西是必须填了才能长按「完成今天」的**。实装时要把旧版遗留的拦截全部去掉，至少包括：

- 重量：任何负重类型（含「自选重量」free_weight、处方只写 RPE 且找不到同序位历史的组）都可以空着完成，存空重量；旧的「还有 N 组需要填重量」「重量 · 必填」提示与校验全部删除。
- 次数、RPE：按显示值记录；处方没写的 RPE 存空。
- 学员自加动作 / 额外组里完全没填的空行：不记录、不提示、不拦截（「至少要有一个动作」之类的提示删除）。
- 视频、动作完成小勾、今日状态问卷：都不是前提。视频没传完沿用现网「先离开，传完才真正完成」。
- 离线：照常进待同步队列，不因断网拦截。

后端「完成今日训练」接口本身没有数据前置条件（已核实 `src/handlers/plan-day-completions.ts`），065 让组重量可空后，客户端不得再自设门槛。

5. **教练端不显示「按计划」**：取消前文「教练端『按计划』」规则。教练 App 的学员日详情 / 组卡片照常同时显示实际值与目标值，一致时自然一致，不加任何标签。
6. **百分比处方的一行写法（B）**：行上只写换算出来的重量，不带括号百分比，如 `1×5 120 · 1×3 150`；百分比在展开区组表的每组行尾以 11pt 次要色小字显示「60%」。换算不出（顶组百分比、顶组未练）时行上仍写「60% 顶组」。


## 走查第 3 轮修订（David 2026-11-11，优先于前文与 spec 092 同项）

1. **教练已发布计划里的每一天都能练**：无论本周、以后的周、以前未结算的周，选中的那一天只要未结算，就与游标日完全同等可练（拍摄、动作完成小勾、点行编辑、加组、加动作、留言、长按完成今天）。取消「以后的周只读预览」「以前的周只读」对**未结算日**的限制，取消 spec 092 已拍板第 6 条「本周没结算完进不了下一周」。
2. 不变：已结算的天仍只读（撤销规则沿用 spec 104 的 7 天窗口）；打开训练页默认仍选游标日（最早一个未结算的训练日）；草稿计划、已暂停 / 已结束计划不可练。
3. 后端「完成今日训练」接口本身不限制顺序（已核实），无后端改动。

验收补充：16. 在 W1 未练完时选中 W2 的某天，能拍摄、编辑、打勾并长按完成；完成后 W1 那天仍是游标日、默认选中；教练端该天显示已完成。
