# 学员「教练」角标已读（spec 108，T1 / P1）

反馈来自 iOS 学员端。进入「教练」时角标隐藏，切回训练又显示 1。截图无法区分这个 1 来自计划、视频反馈还是聊天。

## 复现与验收

- 在 SwiftUI 学员对话视图仅放一条计划通知，打开对话、离开、重载。修前测试得到 1，预期 0。旧逻辑只在点击「去训练看看」时记录已看，选中教练时由 tab 栏暂时隐藏计数。
- 沿用原有学员 ID 和计划签名保存已读。前台对话打开或新签名传入后确认当前计划，卡片保留供查看和跳转。其他 tab 或后台不消费新计划。
- 第二条复现仅一张反馈卡。对话隐藏时布局完成，切回后卡片坐标不变，修前退出刷新仍是 1；改为同时观察前台、tab 可见性与卡片露出比例，保持 55% 门槛。已读请求继续按反馈 ID 去重。
- `swift test --package-path Modules/StudentKit --skip-build --no-parallel` 在本卡构建产物上 **1301/1301** 通过。打开后清计划、静止反馈卡切回、刷新后仍清零，以及已读签名与可见反馈同步均通过。严格 SwiftLint、swift-format 和 diff 检查通过。Standards / Spec 独立审查确认 iOS 无未决项。
- Android 独立复现并修复计划未读及反馈回执失败后的重试，见 [meetpr-rn#197](https://github.com/tianpingdeng112233-cell/meetpr-rn/pull/197)。
- iPhone 17e / iOS 26.5 / MeetPR.xcodeproj / MeetPR-DemoStudent。实屏依次为训练「教练 1」→ 教练（计划卡保留）→ 训练（无角标）→ 成长（无角标）。四张原图在 2026-11-15/dui/outputs。两端使用测试数据，未读取反馈者的真实账号。
