# 学员训练页数字键盘避让

2026-11-26，P1，基于 release/1.0 的 bfd39662，关联 spec 105、107、112。范围限于训练组数字面板的布局与滚动。

iPhone 17e（iOS 26.5），MeetPR-DemoStudent，中文 pct-anchors 场景。在最后一个动作打开重量后，输入格下沿为 496.3 pt，收起键从 466.3 pt 开始。连续点两次键盘上的「加一组」，第 3 组输入格下沿达到 659.3 pt，已被数字键遮住。最初仅调整滚动容器的底部 padding，问题仍可复现。

收起按钮原本向上偏移 48 pt，超出键盘报告给列表的布局范围。切换字段或新增组会重置 session.panelTop，而留在相同高度的测量节点不会再次报告位置。把收起按钮纳入键盘高度，并让测量节点随当前格重新创建，继续使用已有的整行滚动。

在刚启动的中文 DemoStudent 运行以下原生回归。它点底部组、连续加两组、切次数及 RPE，并收起键盘。每步读取真实辅助功能边界及当前键盘标题。

```sh
python3 scripts/verify-all-day-keypad-visibility.py --axe "$AXE" --udid "$IPHONE_17E_UDID"
```

实测重量及次数格下沿 448.3 pt，键盘顶边 466.3 pt。RPE 格下沿 392.3 pt，键盘顶边 410.3 pt。另从收起状态直接打开末组 RPE 并截图。范围为本地演示训练日，未上传测试包。

DesignSystem 全量 83 项、StudentKit 全量 1363 项通过，改动 Swift 文件通过严格格式与 lint 检查。独立 Standards / Spec 复核均通过。根据反馈加固了回归断言，验证每次切换后的真实键盘标题。
