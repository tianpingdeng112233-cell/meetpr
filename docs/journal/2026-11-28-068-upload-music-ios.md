# 学员拍摄和上传视频期间继续播放音乐

基于 release/1.0 的 ca4eaa3e，关联 spec 068 拍摄、027 上传及 113 聊天附件。目标从点开相机开始，覆盖取景、带麦克风录制、回看、从相册选片、裁剪、导出与发送。上传使用已有网络管线。范围限于上传时的音频行为。

## 实现

原录制器使用 AVCaptureSession 默认的自动音频配置。现在从配置相机输入前开始，以允许混音的 playAndRecord 和 videoRecording 模式录制。可使用蓝牙立体声输出。沿用原有麦克风输入、录音样本输出与视频写入路径。iOS 17 与较新系统使用同一实现。

拍摄回看、相册裁剪和聊天预览在播放前取得允许混音的音频会话。相机和多个预览重叠时保留录音能力。最后一个使用者退出时先停用音频会话，再恢复先前类别、模式和选项。纯文件读取、视频导出和分片上传无需占用音频会话。

## 验证

- iPhone 17e 模拟器，iOS 26.5。改前测试在录制器的自动音频配置断言失败。改后验证相机策略、可与其他 App 混音的录音类别、重叠预览，以及最后一个预览关闭后的原始配置恢复。
- 独立模拟音乐 App 循环播放 AAC，通过 AVAudioPlayer 检查播放状态和进度，并监听系统中断通知。启用真实 AVAudioSession 录音类别、处理嵌套预览，以及正式 BackgroundVideoPartUploader 发送本地 HTTP PUT 后，音乐持续播放，中断计数为 0。
- 分片传输在本地测试接收端限速。实际收到 4,194,304 字节，约 2.9 秒，HTTP 200，上传组件成功读回 ETag。没有向学员或教练发送测试数据。
- 从学员训练页展开硬拉，点第一组相机、进入相册、选择 11 秒片段、播放并点上传，返回后该组显示已附视频。此段使用 DemoStudent 界面，独立音乐 App 每半秒采样持续播放，系统中断计数为 0。实际 HTTP 传输另用上述正式上传组件验证。
- StudentKit 包串行运行全部 1,374 项测试通过。
- Standards、Spec 独立只读审查完成。Standards 指出的失败分支已修正，恢复设置成功前保留原快照，并按 iOS 行为处理 isBusy。
- 模拟器缺少实体摄像头。实体 iPhone 实录的声音、实际蓝牙耳机路由和学员音乐 App 的表现待真机验证。
