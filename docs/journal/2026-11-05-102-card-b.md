## 实现

账号独立的原子 JSON 存储保存组操作和完成 intent。界面先入队并立即更新草稿，后台串行发送，网络/超时/5xx 退避重试，网络恢复跳过退避；不可重试 4xx 停止自动发送，显式重试才解除。载入、刷新和切日均叠加本地执行字段，不覆盖教练处方；服务端快照确认后停止本地投影覆盖。

长按完成使用独立协调器，待同步时原位显示状态，20 秒或不可重试错误转失败，重试重新计时。队列为空直接走原奖励。完成闸门落盘，组与视频条件均满足才调用完成接口；启动恢复只接管已存在的 intent。账号级 Host 统一承接学员退出入口，弹窗按逻辑组去重计数，支持上传后退出、直接退出保留和取消。

缺失计划动作按原 exerciseID 转为 092 自加记录；先读取权威账本避开占用槽，再持久化转换索引，失败重试沿用同槽。自加日期沿用日期锚点。保留原额外组／自加组的 e1RM、PR 与重量基线修复。
