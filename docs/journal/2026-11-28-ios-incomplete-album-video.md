# iOS 训练相册视频读不完整

P1，随 1.0 (44)。build 43 能从相册读到截断 MP4 的时长并进入剪辑，全长导出才返回 AVFoundation -11880。6 个 H.264 / HEVC 截断样本均可复现，相应完整文件均可导出。这是合成样本的复现，学员原片未取得。

训练组相机的相册入口、替换视频和丢片重选现在都会检查刚收到的临时副本。检测到空文件，或 MP4 的 mdat 声明长度超过实际文件长度时，以同一个 PhotosPickerItem 重新请求一次。持续短读只清理新副本，在剪辑和上传前提示保存完整原片并重新选择。未确定缺数据的容器继续由原有媒体流程处理。诊断记录固定码 `video.picker.ERR_INCOMPLETE_VIDEO`。

## 验收

- 先红后绿。首次交付截断副本、第二次交付完整副本的测试在修复前只读取 1 次，修复后自动重读成功且第一次副本被清理。另覆盖持续短读、完整与未知容器、取消和固定诊断码。
- iPhone 17e / iOS 26.5 上用实际导入实现复测 H.264 与 HEVC 各三档截断，6 份全部在两次读取后拒绝，原文件保持不变。两份完整 MP4 和一份 MOV 均一次通过，输出与原片逐字节相同。
- StudentKit 1,379 项测试通过。修改的 Swift 文件通过 SwiftLint 和 swift-format 严格检查。独立 Standards、Spec 审查均通过。
- MeetPR-DemoStudent 实际界面：学员空组从相册选截断样本，直接提示「视频文件不完整。请将原视频完整保存到手机后重新选择。」关闭后重选完整样本，可裁剪并显示「已送达教练」。再用残片替换，组内原附件 SHA-256 保持一致，仍可播放至 0:02 / 0:04。交付使用演示后端。[验收截图](../evidence/ios-album-import/verification.jpg)
