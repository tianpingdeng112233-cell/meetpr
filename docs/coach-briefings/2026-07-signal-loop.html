当天到你眼前

这一轮更新解决一件事：不用翻，不用问，打开 app 就知道今天该管谁。学员端记录训练，系统当天判读，教练端只看结论。

02 / 推送

每天早上一条汇总，点开直达看板

不逐条打扰：全天的事收进每天一条「昨日小结」推送。点它直接落在今日看板上，冷启动也一样。首次登录询问一次通知权限，拒绝后不再纠缠。

03 / 学员端

「开始训练」——信号的源头更准了

学员的训练 tab 现在先看到一页训练总览（今天练什么、几组、上次成绩参照），点「开始训练」才进入逐组记录，同时开始计时。今日页顶部常驻一条状态：

学员今日 TAB · 状态条三态
今日 · D 日 · 12 组 › 开始训练
训练中 · 24:37 ›
✓ 今日已完成 · 61 分钟 ›

训练是否完成、练了多久，从此有明确的起点和终点——你在看板上看到的「练完 / 部分完成 / 缺练」，就是从这里来的。深夜训练按凌晨 4 点为界归属「今天」，夜猫子学员不会被误判缺练。

05 / 口径

三种信号，怎么算数

宁可少报，不误报。每条信号都能在学员的训练记录里找到出处：

缺练
连续 3 个计划训练日没有打卡才亮起。补录旧数据会让它自动消失，不用你动手。
被压
当天主项（深蹲 / 卧推 / 硬拉）出现失败组。留因里写清动作、重量、失败几次。
破 PR
e1RM 刷新近 28 天最佳。看板上留给你知情，庆祝交给学员端。
  • 信号 7 天自动过期，看板不会积压旧账。
  • 没有「处理 / 划掉」按钮——它是雷达，不是待办清单。
