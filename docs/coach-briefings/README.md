# 教练汇报页（coach briefings）

面向教练群体的功能更新汇报 HTML,单文件自包含(无外部依赖),可直接发微信/邮件。

## 约定

- 命名:`YYYY-MM-<slug>.html`,一次汇报一个文件,已发出的文件不回改(要更新就出新文件)
- 视觉:沿用 app 设计语言——深底、红仅点睛、mono 标签、灰阶数据分层
- 文案:教练视角白话,零工程术语;界面用 HTML 示意还原,不贴实机截图(避免带出未发布内容)
- 结尾固定含「上线节奏」与反馈渠道
