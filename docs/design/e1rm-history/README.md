## 打开

直接打开 [prototype/index.html](prototype/index.html)，或从此目录运行 `python3 -m http.server 8083 --bind 127.0.0.1` 后访问 `http://127.0.0.1:8083/prototype/index.html`。无需安装依赖。预览自动适应窗口，手机下方可切原尺寸。

## 可体验的路径

1. 成长 → 点击任一节点 → 来源日期、动作与组次、重量 × 次数、采用的 RPE 和算式；关闭后保留范围与滚动位置。30 天／90 天／历史总览可切换。
2. 训练 → 历史记录 → 筛选动作 → 返回训练，演示状态仍是 W3 · D2、第 3/4 组、已记录 2/4 组。
3. 右侧来源示例：教练校准、未填 RPE 的 Epley、原始日志缺失但快照保留、导入记录、无历史。两套主题均可切换。

## 原型边界与下一步

此 HTML 是一次性设计原型，所有训练数据都是内存中的示例。训练记录按钮及本次无关 tab 仅给出提示，不写库；历史只展示有限示例，未模拟真实分页、加载失败、计时和草稿保存。未全面实现低置信隔离点、长周期密集节点、英文及真实持久化恢复；这些要求仍在 spec 中，实装后须验证。
