MeetPR 组件库 STUDENT · v1
7 个组件各是一个独立文件，props 契约写在文件末尾 data-props 的 JSON 里（含 TS 类型）。组件里零硬编码颜色，全部走 var() —— 主题由祖先 .theme-light 决定，组件不接 theme 属性。下面每行左暗右亮，是同一份代码在两个作用域下的渲染。
:root（暗色）.theme-light（亮色）
DayChip 周日历的一格 · 完成 / 未完成 / 休息 / 今天选中 / 未来 —— 休息日不显示状态点
Badge 状态标签 · gold 表示进行中，danger 只给需要处理的异常 · neutral 用 --surface-key，必须放在 --surface-card 上（两者在亮色下只差 2/255，放页底会消失）
SetRow 一组记录 · 成功/失败与视频上传是两个彼此独立的图标
StatTile 数字卡 · 大数字一律 Mono，delta 靠正负号表意而不是箭头
GoldCTA primary 全宽胶囊「开始训练 / 记录此组」· link 是 CTA 下方的小字链接「顺延一天 ›」「未完成 / 失败」，不是胶囊 · secondary 只出现在弹窗里（顺延确认的「取消」）· danger 学员端只有「退出登录」一处
ExerciseCard 动作卡 · 展开时内部渲染 SetRow；全部记录完毕后收成一行摘要（点标题切换）
NumberPad 数字键盘 · 次数模式禁用小数点；重量吸附 0.25kg、区间 20–500，次数 1–100
