# MeetPR Design System

从 **MeetPR 学员端**（力量举训练 App，暗色 + 亮色双主题）拆解出的设计系统。源头是本项目的 `MeetPR 学员端.dc.html`（暗色，默认主题）与 `MeetPR 学员端 亮色.dc.html`，双主题入口 `MeetPR 学员端 双主题.dc.html`。教练端（`MeetPR 教练端*.dc.html`）沿用同一语言。

## 产品语境
MeetPR 是力量举（蹲/推/拉）训练记录与教练协作工具。学员端核心流程：今日概览 → 训练清单 → 逐组记录（重量/次数/RPE/视频）→ 完成庆祝 → 训练回顾。视觉基调：硬核、克制、数据为主角；金色只服务于「行动」与「进行中」。

## CONTENT FUNDAMENTALS（文案基本面）
- 语言：简体中文为主，数据/单位用等宽西文（`175 KG`、`W1D4`、`@8.5`）。
- 人称：对用户直接祈使，不用「您」：「开始训练」「记录此组」「完成本组」。
- 结构：短语化、名词化，常用 `·` 作分隔：「蹲 · 推 · 拉」「共 3 个动作 · 7 组」「上次 170kg×3 @8 · 最佳 175kg×3 @8.5」。
- 数字规范：重量保留必要小数（172.5），组数/次数一位整数（动作序号 1/2/3，不用 01）；周期标记 `W{周}D{天}`。
- 情绪：完成时刻允许庆祝（「今日训练完成」+ 奖牌 + 火花），日常界面零感叹号、零 emoji。
- 反馈与提示：说明后果而非命令，如顺延弹窗「本次训练将顺延到明天…教练会收到通知」。

## VISUAL FOUNDATIONS（视觉基本面）
- **色彩**：一个金色系（CTA 实体 `#FFB800`，点缀 `#F5A623`）+ 中性灰阶 + 双语义色（成功绿/失败红）。暗色是默认主题：底 `#0A0A0C` < 嵌入 `#101014` < 堆叠 `#121217` < 卡片 `#141416`，靠层级而非阴影分层，禁纯黑大面积。亮色页底 `#F5F6F8`（忌纯白页底），白卡 + 弥散阴影 `0 4px 18px rgba(17,24,39,.06)`；金色在白底降为琥珀 `#D97706`。
- **字体**：Archivo（800/900，标题与大数字）+ IBM Plex Mono（数据、标签，letter-spacing .05em）+ IBM Plex Sans / Noto Sans SC（正文）。整数字号阶梯 10→54，无半像素。
- **圆角**：四档 — 10（小块）/ 12（控件、内表）/ 16（卡片）/ 20（弹窗），CTA 与标签一律 999 胶囊。
- **按钮**：主 CTA（暗色）纯色 `#FFB800` 黑字 + 顶部内高光 + 底部暗边 + 金投影；最重要的入口（开始训练）额外有 4.5s 斜向光泽扫过。亮色主 CTA 用深蓝黑 `#111827` 白字。次级：暗色 `#141416` 描边卡片按钮；文字链下划线灰。
- **动效**：按压统一 scale(.97) 120ms（`.pb`）；进场用错峰上浮（500ms easeOutCubic，40–90ms stagger）；收纳用卷折（scaleY + translate）；完成庆祝 = 光焰 bloom + 盖章 + 火花粒子。金色发光呼吸 4.2s 用于「进行中」。
- **边框**：暗色 1px `#1E1E22`–`#262629`；选中态 1.5px 金描边；亮色以阴影代替描边。
- **透明与模糊**：仅遮罩层用 `rgba(0,0,0,.55)`；毛玻璃只用于深色半透按钮（backdrop-blur 8px），不滥用。
- **图表**：容量柱 = 金色渐变柱（上亮下暗透明），强度线 = 细 1.2px 浅灰线 + 2.6px 圆点，双轴小字 9px mono。
- **状态点**：5px 圆点 — 绿=已完成，金/橙=进行中，红=未完成；休息日整体降灰不打点。

## ICONOGRAPHY
- 全部为内联 stroke SVG，2–2.6px 线宽、round cap/join，风格与 **Lucide** 一致（可用 Lucide CDN 补充，需保持 stroke-width≈2.2）。
- 无图标字体、无 emoji（唯一具象徽章是完成页的 SVG 奖牌，项目内绘制）。
- 语义惯例：▶ 开始、✓ 完成（绿）、✗ 失败（红）、摄像机 = 视频上传状态（绿=已传/灰=未传）。
- 品牌标识：源文件中无正式 logo，用 Archivo 900 字标「MEETPR」代替；未自造 logo。

## Tokens
`styles.css` → `tokens/{fonts,colors,typography,spacing,effects}.css`。暗色即 `:root` 默认值；亮色作用域 `.theme-light`。

## 目录索引
- `styles.css` — 全局入口（只含 @import）
- `tokens/` — 色彩 / 字体 / 字号 / 间距圆角 / 阴影动效
- `guidelines/` — Foundations 规范卡片（Design System 标签页可视）
- `components/core/` — Button / Badge / Card / DayChip / SetTable / TabBar（.jsx + .d.ts + .prompt.md）
- `SKILL.md` — Claude Code 可用的技能入口
- 源 UI：`MeetPR 学员端 双主题.dc.html`（完整交互样机，即事实上的 UI kit）

## Intentional additions
- 无新增组件；组件清单全部来自学员端既有元素。

## 注意
- 字体走 Google Fonts CDN（源应用即如此），无本地字体文件。
- 设备外壳（iPhone 边框 46/58px 圆角）属演示容器，不属于产品 UI 规范。
